# Interview Manager

管理 `~/.interview/` 目录下的候选人信息和面试题。

## 命令

| 命令 | 用途 |
|------|------|
| `python3 scripts/interview.py list` | 列出所有候选人及状态 |
| `python3 scripts/interview.py list --all` | 列出候选人（含已归档） |
| `python3 scripts/interview.py generate <名> --level senior` | 生成面试题模板（senior: 2维度） |
| `python3 scripts/interview.py generate <名> --level mid` | 生成面试题模板（mid: 3维度，默认） |
| `python3 scripts/interview.py feedback <名> --score 45 --rating A` | 记录面试反馈 |
| `python3 scripts/interview.py archive <名>` | 归档已面试候选人 |

## 面试题设计规范

### 题目数量控制
- **总题数控制在 6-8 题**，每题 5 分，总分 40-45 分
- Senior（2维度）：每维度 3-4 题，合计 6-8 题
- Mid（3维度）：每维度 2-3 题，合计 6-8 题

### 题目组织方式（按项目聚焦）
1. **按项目分组**：同一项目/经历的题目归为一组，方便面试时围绕一个项目深入追问
2. **每题标注**：
   - 考察维度（学习能力 / 毅力 / 智力）
   - 分类标签（如 `技术架构` `性能优化` `跨技术栈协作`）
3. **评分标准**：每题 1-5 分，附具体行为锚点（避免"较好""一般"等模糊词）
4. **一票否决项 & 红旗信号**：标注得分≤1或≤2的隐患含义

### 评分等级

| 总分 | 评级 | 判断 |
|------|------|------|
| 36-45 | A | 强烈推荐，底层能力突出 |
| 28-35 | B | 推荐，底层能力合格 |
| 21-27 | C | 待定，需要额外验证 |
| <21 | D | 不推荐，底层能力不足 |

## 评估框架

候选人按年限分级评估：
- **Senior (10+年):** 学习能力 + 毅力（2维度，50/50，每维度 3-4 题，合计 6-8 题）
- **Mid (2-3年):** 智力 + 学习能力 + 毅力（3维度，35/35/30，每维度 2-3 题，合计 6-8 题）

评分：每题1-5分，总分 40-45 分（根据实际题数）
- A (36-45): 强烈推荐
- B (28-35): 推荐
- C (21-27): 待定
- D (<21): 不推荐

## 依赖

- Python 3.8+，标准库 only

## 最佳实践

### 面试题生成后的优化流程
1. **简历分析**：先用 `pdftotext` 提取简历文本，了解候选人核心经历
2. **题目精简**：按项目聚焦，总题数控制在 6-8 题，合并高度相关的题目
3. **维度平衡**：确保每道题都有明确的考察维度标注（学习能力/毅力/智力）
4. **分类标签**：每题开头标注分类标签（如 `技术架构` `性能优化` `组织推动`），便于快速定位
5. **评分标准**：1-5 级行为锚点要具体，避免模糊词，标注红旗信号和一票否决项
