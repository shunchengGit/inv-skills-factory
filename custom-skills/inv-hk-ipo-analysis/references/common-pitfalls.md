# 港股IPO分析常见陷阱

| 陷阱 | 防范 |
|------|------|
| **用过期新闻判断市场情绪** | 搜索时注意文章日期，半年以上的新闻不能代表当前市场。同一话题可能有不同时期的矛盾报道，需综合判断时效性 |
| **忽略二次递表信号** | 首次递表失效后重新递交，说明公司可能面临聆讯问题或市场窗口问题 |
| **只看亏损不看现金消耗率** | 亏损额含大量非现金项目（股份支付），要看经营现金流判断真实烧钱速度 |
| **忽略基石禁售期** | 6个月后解禁压力大，打新者不应持有超过首日 |
| **18A公司估值失真** | 未盈利生物科技公司PS极高是常态，不能简单用PS判断贵贱 |
| **单一来源判断市场情绪** | 不要只靠一篇文章就下结论，应搜索多个来源交叉验证 |
| **web_extract 403降级** | 若目标网站返回403（如CloudFront拦截），可直接读取搜索结果的标题和摘要作为替代信息源 |
| **web_extract Cloudflare Challenge** | 部分财经站点返回"安全验证中"占位页，正文为空。降级路径：(1)换搜索结果中的其他源；(2)用 facebook.com 上的券商IPO公告页常可直接抓取 |
| **无基石投资者的确认** | 搜索全文若未找到「基石投资」相关章节，需在分析中明确标注「无基石投资者」并评估为利空信号 |
| **盲读零散页而非先建关键词地图** | 对100页以上招股书必须严格按第一步先扫描全文建立关键词地图再定向提取 |
| **重复计算第三方已算好的数据** | 打和点、孖展利息等数据，talkmoney.com.hk / sl886.com / aastocks 等第三方IPO攻略文已算好，优先复用但需交叉验证至少2源 |
| **A+H股定价锚定** | A+H上市公司，H股发售价通常参考A股近期均价。需对比A股现价与H股发售价，判断折溢价空间（详见 `references/hk-a-plus-h-listing-analysis.md`） |
| **A+H 蓝筹孖展冷淡≠利空** | A+H大盘股（集资50亿+）孖展超购仅1-2倍是常态而非破发信号。判断标志：(1)国际发售已足额认购报道；(2)基石占发售股份>35%；(3)集资规模>50亿。**核心规则：孖展热度只对中小盘炒作型新股有意义，对A+H蓝筹股要看基石质地+AH折价** |
| **招股书表格错位** | 财务表格在纯文本提取时可能错位，关键数字需交叉验证多页提取结果 |
| **基石投资者分散多页** | 基石名单常分散在几十页中，需用全文搜索模式(1C)而非逐页浏览提取 |
| **talkmoney.com.hk 内容多为AI生成** | 该站IPO攻略文常含自相矛盾的数字。**禁止直接引用其数字**，仅用作"散户视角和孖展利率比较"的定性参考 |
| **talkmoney.com.hk 可能整体认错产品性质** | 不止数字错，还可能把整个标的性质都搞错。**先用招股书第1-2页确认发行性质**（H股/红筹/HDR/REIT/ETP/SPAC），再去交叉验证第三方资料 |
| **DR/HDR二次上市需特殊框架** | 港股发预托证券(HDR)对应印尼/其他市场已上市的母股时，估值锚是母股现价，不是同行PE/PS。详见 `references/hk-dr-second-listing-analysis.md` |
| **辉立cyberquote URL是HTTP明文** | URL是HTTP明文，curl下载会触发安全告警但内容可信（辉立证券官方研报）。**这是港股每只新股最稳定的一手研报源，每次都该拉** |
| **多新股横向对比凭印象估算** | 用户陆续追加招股书要"赢面排序"时，必须每只都拉准4个字段（入场费/市值/基石占比/**上市日**）再给横向表。详见 `references/hk-ipo-batch-comparison.md` |
| **同招股期≠同上市日** | 一批同时招股的新股，上市日可能分两批甚至三批。横向表必须有"上市日"列，独立窗口的新股反而是优势（避开资金分流），齐挂5只+的批次要扣分 |
