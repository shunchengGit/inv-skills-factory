# 港股IPO招股书PDF提取实战模式

> 从芯碁微装(09630.HK)招股书(517页)提取实践中总结

## 模式一：关键词地图 → 定向提取（推荐用于100页以上）

**适用场景**：大型招股书(400页以上)，信息分散在多个章节

**步骤**：
1. 先用关键词扫描全文档，建立关键词→页码映射
2. 根据映射结果，定向提取关键页面
3. 对分散信息(如基石投资者名单)，使用全文搜索模式

**关键代码**：
```python
import fitz  # pymupdf

doc = fitz.open('/path/to/prospectus.pdf')

# 1. 建立关键词地图
keywords = ['基石', '財務資料', '行業概覽', '風險因素', '所得款項', '業務', 
            '公司資料', '發售價', '市值', '虧損', '收入', '研發', '現金']
for kw in keywords:
    pages_found = []
    for i in range(doc.page_count):
        if kw in doc[i].get_text():
            pages_found.append(i+1)
    print(f'{kw}: 第{pages_found[:5]}页... (共{len(pages_found)}页)')

# 2. 定向提取关键页面
key_pages = [(9, '公司资料'), (84, '行业概览'), (18, '财务资料'), 
             (71, '基石投资者'), (56, '所得款项')]
for pg, label in key_pages:
    text = doc[pg-1].get_text()
    print(f'=== 第{pg}页 ({label}) ===')
    print(text[:2500])

# 3. 全文搜索分散信息（如基石投资者完整名单）
for i in range(1, doc.page_count + 1):
    text = doc[i-1].get_text()
    if '基石投資' in text:
        print(f'=== 第{i}页 (基石投资) ===')
        print(text[:2000])
```

## 模式二：章节跳跃提取（适用于已知章节结构）

**适用场景**：招股书结构标准，已知关键章节大致位置

**常见章节页码分布**（以500页招股书为例）：
- 概要/重要提示：第1-10页
- 风险因素：第20-60页
- 行业概览：第70-100页
- 业务：第100-180页
- 财务资料：第200-280页
- 基石投资者：第200-230页（常在财务资料之后）
- 未来计划及所得款项用途：第250-270页
- 附录（会计师报告）：第300页以后

## 模式三：财务表格提取（处理错位问题）

**问题**：财务表格在纯文本提取时列对齐可能错位

**解决方案**：
1. 多页交叉验证：同一财务数据常在概要和附录中重复出现
2. 优先使用附录中的正式财务报表（会计师报告部分），而非概要中的摘要
3. 对关键数字（如收入、利润），从多个来源提取并比对

```python
# 示例：从附录提取正式资产负债表
for i in range(310, 340):  # 附录区域
    text = doc[i-1].get_text()
    if '流動資產' in text and '現金及現金等價物' in text:
        print(f'=== 第{i}页 (资产负债表) ===')
        print(text[:3500])
```

## 常见陷阱与对策

| 陷阱 | 对策 |
|------|------|
| 基石投资者分散在几十页中 | 使用全文搜索，不要逐页浏览 |
| 财务表格列错位 | 多页交叉验证，优先附录正式报表 |
| 中英文关键词混用 | 同时搜索中文和英文关键词（如"基石"和"Cornerstone"） |
| 页码与实际PDF页码不一致 | 注意招股书页眉可能有"第X页"标注，与PDF页码不同 |
| 大量重复内容（如免责声明） | 设置合理的text[:N]截断，避免输出过长 |
| 表格数据在文本中丢失结构 | 手动重建表格结构，或使用正则提取关键数字 |

## 输出结构建议

提取完成后，按以下结构整理：

```
## 一、公司基本资料
- 公司名称、代码、行业、注册地
- 全球发售股份数、发售价范围、市值

## 二、财务数据摘要
- 收入、毛利、净利润（最近3年）
- 毛利率、净利率趋势
- 现金及现金等价物
- 经营现金流

## 三、业务与行业
- 主营业务及收入结构
- 行业地位及市场份额
- 行业规模及增长率

## 四、基石投资者
- 名单及认购金额
- 背景分析（产业资本/国际机构/地方国资等）
- 禁售期

## 五、所得款项用途
- 资金分配比例
- 用途合理性评估

## 六、风险因素
- 核心风险（客户集中、现金流、竞争等）
- 特别关注点（制裁、关联交易等）

## 七、估值分析
- 市盈率、市销率
- 与同行对比
- A+H股溢价/折价（如适用）

## 八、综合评估
- 投资亮点
- 主要风险
- 建议
```
