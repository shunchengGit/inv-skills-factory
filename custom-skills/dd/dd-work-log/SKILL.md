# dd-work-log：工作记录管理

**基于微云知识库的工作记录管理。** 底层存储委托给 `dd-skills-memory` 统一服务，**强制使用微云后端**。

## 命令语义

| 命令 | 语义 | 存储操作 |
|------|------|---------|
| `/wl_init` | 初始化/读取当月工作记录文档，输出全量记录 JSON | `sm.get_or_create_doc("dd-work-log", "YYYY-MM")` + `sm.read_doc` |
| `/wl_add <内容> [--date YYYY-MM-DD] [--tag 标签]` | 添加工作记录到当月文档 | `sm.read_doc` → 解析 → 追加 → `sm.update_doc` |
| `/wl_list [--year YYYY] [--month MM]` | 列出指定月份的工作记录 | `sm.get_or_create_doc("dd-work-log", "YYYY-MM")` + `sm.read_doc` |
| `/wl_search <关键词> [--year YYYY] [--month MM]` | 搜索工作记录 | `sm.read_doc` → 按关键词过滤 |
| `/wl_report --type daily/weekly/monthly` | 生成日报/周报/月报 | `sm.read_doc` → 按日期聚合 → 格式化输出 |

## 记录格式

每个任务行包含 ID，日期和标签统一放在末尾：

```markdown
# 2026年6月 工作记录
- [#abc1234] 完成需求评审 [2026-06-13] [项目A]
- [#def5678] 修复线上bug [2026-06-12] [紧急]
```

- ID 格式：`[#xxx]`，放在任务内容前面
- ID 生成算法：任务内容的 sha1 哈希取前 7 位
- 日期格式：`[YYYY-MM-DD]`，作为标签放在末尾
- 标签格式：`[标签名]`，支持多个，放在任务内容后面
- 日期和标签顺序不限，统一按标签处理

## 文档命名约定

| 文档 | 命名格式 | 用途 | 内容格式 |
|------|---------|------|---------|
| YYYY-MM | `2026-06` | 按月存放工作记录 | 按日期排序的列表 |

## 报告格式

### 日报

```markdown
# 2026-06-13 工作日报

## [项目A]
- 完成需求评审
- 编写技术方案

## 其他
- 参加周会

**总计：3 条记录**
```

### 周报

```markdown
# 2026年第24周 工作周报

**周期：2026-06-09 ~ 2026-06-15**

## 2026-06-13 周五
- 完成需求评审 [项目A]

## 2026-06-12 周四
- 无记录

## 本周标签汇总
- **项目A**：2 条
- **紧急**：1 条

**本周总计：3 条记录**
```

### 月报

```markdown
# 2026年6月 工作月报

## 2026-W24
### 2026-06-13 周五
- 完成需求评审 [项目A]

## 本月标签汇总
- **项目A**：5 条
- **紧急**：2 条

**本月总计：8 条记录，覆盖 6 天**
```

## 配置

**本技能强制使用微云知识库存储，不可配置为其他后端。**

所有存储操作通过 `dd-skills-memory` 统一服务完成，后端固定为 `weiyun`：

| 环境变量 | 说明 | 固定值 |
|---------|------|--------|
| `SM_BACKEND` | 存储后端 | `weiyun`（不可更改） |

> ⚠️ **强制要求**：必须使用微云知识库作为存储后端，以确保工作记录在多设备间同步。
> 调用 `dd-skills-memory` 时不应覆盖后端配置。

## 依赖

- `dd-skills-memory`（统一存储服务，微云后端）

## 典型工作流

```
1. /wl_init                                    ← 读取当月工作记录文档
2. /wl_add "完成需求评审" --tag 项目A          ← 添加记录
3. /wl_list                                    ← 查看当月所有记录
4. /wl_search "项目A"                          ← 搜索包含"项目A"的记录
5. /wl_report --type daily                     ← 生成日报
6. /wl_report --type weekly                    ← 生成周报
7. /wl_report --type monthly                   ← 生成月报
```

## 特性

| 特性 | 说明 |
|------|------|
| 存储 | 委托给 dd-skills-memory，**强制微云后端**，多设备同步 |
| ID 追踪 | 基于 sha1 哈希的 7 位 ID，支持精确匹配 |
| 归档 | 按月自动分文档存储 |
| 标签 | 支持多标签分类，日期也作为标签统一处理 |
| 搜索 | 支持按关键词搜索 |
| 日报 | 按标签分组展示当日记录 |
| 周报 | 按天展示本周记录，含标签汇总 |
| 月报 | 按周分组展示当月记录，含标签汇总 |
