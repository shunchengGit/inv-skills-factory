# 腾讯前置指标逻辑框架

## 各指标对腾讯的传导机制

### 游戏版号发放 → 游戏收入（Tier 1，权重25%）

腾讯国内游戏收入占比约20%，是最大单一业务。版号是外生政策开关——2022年停发8个月导致游戏收入负增长，2023年恢复后反弹。

- 传导路径：版号数量↑ → 新游pipeline获批 → 上线节奏加快 → 游戏收入↑
- 时滞：版号获批到游戏上线约 3-9 个月，到收入确认再加 1-2 个月
- 关键阈值：月均 < 50 偏紧；> 80 宽松
- 数据来源：国家新闻出版署月度公告（搜索补充）
- 特别关注：腾讯及关联公司当月获批数量、是否有重磅 IP 产品获批

### 王者荣耀 + 和平精英 iOS 畅销榜 → 游戏基本盘（Tier 1，权重20%）

两款产品贡献腾讯国内游戏收入 40-50%，是现金牛。畅销榜排名变化领先财报收入确认约 1 个月。

- 传导路径：畅销榜排名稳定 TOP3 → 流水稳定 → 游戏收入基本盘稳固
- 时滞：排名变化到流水变化几乎即时
- 数据来源：Apple App Store 中国区 Top Grossing RSS（免费、实时）
- 评分参考：
  - 王者 #1 且 和平 #1-3 → +0.5~+0.7（双核稳固）
  - 王者 TOP3 且 和平 TOP5 → +0.2~+0.4（健康）
  - 任一跌出 TOP10 → -0.3~-0.5
  - 双跌出 TOP10 → -0.6~-0.8

### 社零增速 → 广告 + 金融科技（Tier 2，权重15%）

腾讯广告（品牌预算）和金融科技（支付笔数）直接挂钩消费。社零是宏观消费最综合指标。

- 传导路径：社零↑ → 消费信心恢复 → 品牌广告预算↑ + 线下支付↑ → 广告+Fintech 双受益
- 时滞：领先广告和支付收入 1-2 季度
- 数据来源：东方财富宏观 API，脚本自动获取
- 评分参考：社零 > 5%=+0.5~+0.7；3-5%=+0.1~+0.3；0-3%=-0.1~-0.3；< 0%=-0.5~-0.7

### 视频号使用时长 → 广告增长期权（Tier 2，权重15%）

视频号是腾讯当前最大增长期权。时长是最核心的基础设施——时长不够，加载率再提也伤害体验。

- 传导路径：视频号时长↑ → 广告库存增加 → 加载率提升空间↑ → 广告收入↑
- 数据来源：腾讯业绩会管理层口述 + QuestMobile/极光第三方估算
- 无公开精确数据（搜索补充）
- 评分参考：时长环比增 > 10%=+0.5~+0.7；5-10%=+0.2~+0.4；持平=0~+0.1；下降=-0.3~-0.5

### 微信支付商业笔数增速 → Fintech（Tier 2，权重15%）

金融科技收入占比 25-30%，支付笔数是最一线的消费者行为数据。

- 传导路径：商业支付笔数↑ → 手续费收入↑ + 沉淀资金↑ → Fintech 收入↑
- 数据来源：腾讯业绩会管理层披露（每季度）
- 搜索补充
- 评分参考：增速 > 10%=+0.4~+0.6；5-10%=+0.1~+0.3；0-5%=-0.1~-0.3；< 0%=-0.4~-0.6

### 港股通南向净流入 → 估值修复信号（Tier 3，权重10%）

北水是港股边际定价力量。持续流入 → 估值修复；持续流出 → 估值折价。

- 传导路径：北水持续净流入 → 买盘支撑 → 股价底部抬升 → 估值修复
- 数据来源：akshare stock_hsgt_fund_flow_summary_em（日度），脚本自动获取
- 评分参考：5日 > 100亿=+0.5~+0.7；50-100亿=+0.2~+0.4；流出 > 30亿=-0.4~-0.6

## 权重依据

| 指标 | 权重 | 依据 |
|------|------|------|
| 游戏版号 | 25% | 最大单一业务的外生政策开关，历史数据证明影响力 |
| 王者/和平畅销榜 | 20% | 现金牛健康度，贡献国内游戏收入 40-50% |
| 社零增速 | 15% | 宏观消费温度计，影响广告+Fintech 两大板块 |
| 视频号时长 | 15% | 最大增长期权，决定广告增速天花板 |
| 微信支付笔数 | 15% | Fintech 最微观先行指标 |
| 港股通南向 | 10% | 资金面信号，影响短期估值方向 |

## 评分流程

1. 读取 JSON 快照，获取脚本自动获取的 3 个指标
2. 对 agent_required 指标（游戏版号、视频号、支付笔数），按 search_hint 搜索补充
3. 对每个指标独立评分（-1.0 到 +1.0），参考 scoring_guide
4. 按权重加权汇总
5. 考虑指标间交互效应：
   - 版号宽松 + 王者和平 TOP3 → 游戏板块强利好
   - 社零低迷 + 支付笔数下降 → 消费双杀
   - 南向持续流入 + 视频号增长 → 估值+业绩双击
6. **AI进展定性评估**：读取 `references/ai-progress-tracker.md`，结合最新财报数据评估AI对投资逻辑的影响，作为报告的补充章节（不参与加权评分，但影响综合判断的置信度和方向微调）
