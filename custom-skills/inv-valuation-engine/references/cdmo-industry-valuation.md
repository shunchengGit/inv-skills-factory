# CDMO / CRDMO 行业 QARP 估值指南

## 适用标的
药明生物、三星生物、Lonza、富士Diosynth、Catalent、金斯瑞等生物药研发生产外包公司。

## 行业特征与估值影响

| 特征 | 估值影响 | 关键指标 |
|------|---------|---------|
| 管线驱动收入 | 收入预测需基于项目数+转化率 | 综合项目数、Win-the-Molecule胜率、商业化阶段项目占比 |
| 产能扩张周期 | FCF/净利润波动大(-7%~53%实测) | CapEx/净利润比率、产能利用率、PPQ排期 |
| 客户粘性极高 | 商业化阶段切换成本极高 → LTV长 | 商业化项目数、单客户贡献趋势 |
| 地缘/监管风险 | 常为 thesis breaker | 北美收入占比、生物安全法案进展 |
| 毛利率=护城河代理 | 高毛利→技术平台优势+定价权 | 毛利率(药明46% vs 三星35% vs Lonza28%) |
| 订单储备=前瞻指标 | Backlog转化节奏决定收入增速 | 3年内未完成订单、总订单、里程碑付款 |

## 优先估值指标
- **主指标**：PE（盈利稳定后）、DCF（需假设FCF转化率随产能周期改善）
- **次要指标**：PS（早期/亏损阶段）、EV/EBITDA（重资产+杠杆公司）、PEG（增速明确时）
- **行业特有**：订单/Backlog倍数（总订单/年营收）、项目管线深度

## 三场景估值要点
- **增速假设是最大分歧点**：历史CAGR受新冠/法案冲击失真，应以前瞻项目转化+订单释放为基准
- **悲观场景**：假设地缘风险升级+融资冰冻 → 增速5-10% → PE 15-18x
- **基准场景**：非新冠内生增速15-17% → PE 22-26x（CDMO龙头合理区间）
- **乐观场景**：Win-the-Molecule加速+商业化放量 → 增速20%+ → PE 28-32x

## CapEx 质量判断标准
| CapEx/净利润 | 判断 | 说明 |
|-------------|------|------|
| >80% | ⚠️ 警惕 | 扩张过激进，若利用率不足→折旧吞噬利润 |
| 50-80% | 扩张期正常 | 需跟踪利用率提升节奏 |
| <50% | ✅ 优秀 | 产能成熟期，FCF释放加速 |

## QARP 三闸门特别关注
1. **商业模式闸门**：重点看"北美收入占比+地缘风险是否可控"
2. **财务质量闸门**：重点看"FCF转化率趋势+CapEx/净利润+ROE能否随产能成熟回到15%+"
3. **管理层闸门**：重点看"回购vs CapEx的平衡"、"产能扩张是否匹配订单增速"

## 典型 thesis breaker
- 生物安全法案/类似立法通过 → 北美收入直接面临腰斩
- 毛利率从40%+跌至30%以下 → 价格战或技术优势丧失
- 产能利用率持续低于50% → 投资回报恶化

## FCF 转化率改善路径（典型）
```
重扩张期(2022): FCF/NI = -7% (CapEx 120%NI)
扩张中期(2023): FCF/NI = 13% (CapEx 90%NI)
产能释放期(2024): FCF/NI = 38% (CapEx 80%NI)
成熟收获期(2025): FCF/NI = 53% (CapEx 76%NI) → 目标: 60%+
```
