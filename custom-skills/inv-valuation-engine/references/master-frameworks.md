# 价值投资大师估值框架详解
## 1. 巴菲特/芒格估值框架（适用于所有类型标的，核心框架）
### 核心逻辑
买股票就是买公司，只有满足「好生意+好管理层+好价格」三个条件才会买入，赚企业长期成长的钱。
### 判断步骤
1. **判断好生意**：是否具备至少一种宽护城河（无形资产/成本优势/网络效应/转换成本），长期ROE≥15%，现金流健康。
2. **判断好管理层**：是否诚实、理性、以股东利益为先，历史上没有乱多元化、乱投资、损害小股东利益的记录。
3. **计算好价格**：用DCF自由现金流折现法计算未来10-20年自由现金流现值，并按 `scoring-rules.md` 中对应标的类型的安全边际要求判断是否值得买入。
### 卖出条件
- 基本面恶化、护城河消失
- 股价明显高估，安全边际完全消失
- 发现更好的投资标的

## 2. 段永平估值框架（适用于消费/互联网/科技龙头）
### 核心逻辑
商业模式>企业文化>价格，合理价格买入伟大公司，远好于便宜价格买入普通公司，不需要追求极端低估。
### 判断步骤
1. **商业模式第一**：优先选择「赚钱不辛苦」的商业模式，不用持续大额资本投入就能持续产生现金流，毛利率≥30%，净利率≥15%。
2. **企业文化第二**：管理层是否「本分」，聚焦主业，不搞短期投机，不盲目扩张。
3. **价格第三**：计算长期年化预期收益率，并按 `scoring-rules.md` 的五档区间判断便宜程度；≥10%通常至少能支持“合理”，>15%才更接近“合理偏低”或“低估”。
### 估值公式
```
年化预期收益率 = 净利润复合增速 + 股息率 - 估值变化率
```
目标：年化收益率≥10%。

## 3. 彼得·林奇估值框架（适用于成长股/中小盘股）
### 核心逻辑
增长率是最好的估值锚，PEG是判断成长股估值合理性的核心指标，寻找被市场忽略的隐形冠军。
### 判断步骤
1. 确定公司未来3年的净利润复合增速（取机构一致预期的下限，保守估计）。
2. 计算PEG=当前PE / 未来3年净利润复合增速。
3. 按 `scoring-rules.md` 进行五档判断：PEG<0.6 为低估，0.6-0.8 为合理偏低，0.8-1.2 为合理，1.2-1.5 为合理偏高，>1.5 为高估。
### 注意事项
- 周期股不适用PEG估值
- 增速低于10%的成熟公司不适用PEG估值
- 要考虑业绩增速的可持续性，避免短期高增速的陷阱

## 4. 约翰·邓普顿估值框架（适用于周期股/困境反转股/海外市场标的）
### 核心逻辑
逆向投资，在市场极度悲观的时候买入，寻找全球范围内最便宜的标的，追求极致的安全边际。
### 判断步骤
1. 判断行业周期位置：是否处于周期底部，全行业亏损，大部分公司破产退出。
2. 计算内在价值，并优先采用 `scoring-rules.md` 中周期股/困境反转股的安全边际要求；通常只有安全边际≥50%才值得重点关注。
3. 极度分散投资，单个标的仓位不超过5%，避免黑天鹅风险。
### 卖出条件
- 周期见顶，行业景气度达到顶峰，所有人都看好该行业
- 价格上涨到接近内在价值，安全边际消失
- 发现更便宜的标的
