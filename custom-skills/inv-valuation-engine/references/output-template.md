# 估值输出模板

## 结论与状态

- 数据状态、主估值是否已核验、主要缺口。
- 无核验主估值：仅诊断，不给整体评级；任何状态均不自动映射买卖。
- verified只表示研究者核验声明，不代表程序认证经济判断。

## 一主一辅

- 企业经济类型、主方法及选择原因。
- 原文来源、日期、币种、利润/权益/现金流口径。
- 辅助方法、结论一致或冲突、冲突解释。
- PEG、历史分位、卖方目标价如需展示标为背景，不投票。

## 可选标签与程序边界

五档 conclusion 可缺省/null，不是就绪必需输入；有标签时只作展示。confidence 不再由诊断评级计数，程序不认证研究置信度。辅助 assessment 可有分歧，非 consistent 必须填写 explanation（分歧根源、采用理由及风险）；不要求人为凑一致。

终值折让输出名为 terminal_value_discount_pct，旧 margin_of_safety_pct 仅兼容读取，不等于当前内在价值安全边际。动作空值表示估值与QARP资本配置分离，不等于估值门禁失败。

默认只请求核心 all；日线、公告、调研显式按需。缺口 scope=background 只作背景披露，未标记则保守作为 core。核心快照 failed 阻止主估值；其他 partial、fallback 或 core 缺口令核验主估值受限为 partial。价格/币种或主估值结构缺失仍不能放行。比较按输入顺序列核验主估值三情景、来源/日期/币种/期限；不同经济结构和风险不能机械排名。

## 三情景

保守、基准、乐观分别列期限、终值盈利或现金流、退出估值、稀释、可收分配、成本、总回报和年化回报。明确来源及自建假设。程序只用当前价、期限、未来每股终值及累计每股分配计算总回报与简化年化：分配期末归集，不再投资，不按现金流日期折现，不等于IRR；不自动计算税费、汇率、稀释，需输入及假设注明净额口径。详见 scoring-rules.md 公式与兼容保留清单。

区分今天价值与未来退出价值，不把未来价差称今天安全边际。分配期末归集的简化年化不是IRR；需要时用实际时间现金流核算。

## 关键假设与证伪

只列决定价值的少数变量、情景损失及生存能力，安全边际不用固定行业折扣。说明何种事实需要复核。

## 资本配置接口

买卖结论由QARP统一结合组合约束、同口径替代机会与交易成本给出；估值标签不触发动作。
