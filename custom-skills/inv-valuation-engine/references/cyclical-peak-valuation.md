# 极端周期股峰值盈利估值纪律

## 何时启用

对以下标的跑五档结论**之前**先套用本纪律：

- 商品化制造：存储器（DRAM/NAND/HBM）、面板、航运、化工、锂/钴、钢铁、纯碱
- 特征信号（命中任意 2 条即视为极端周期状态）：
  - 产品现货价同比 +200% 以上
  - 卖方模型里 2 年内营收增长 3 倍以上
  - 当期营业利润率处于历史最高（如 OPM 70%+ 的制造业）
  - forward PE 掉到 2-5x，而 trailing PE 还有 20-30x

**核心命题**：周期顶部的低 PE 不是安全边际，是分母失真。QARP 的「好价格」必须用正常化盈利定义，不能用峰值盈利定义。

## 一、峰值检验（三个必做算术）

### 检验一 · 营收倍数外推检验

把卖方 2 年后的营收除以周期起点营收。若倍数 ≥3x，则这份模型隐含「当前价格尖峰长期化」。

明确写出来：「这要求 ASP 长期停在当前 +XXX% YoY 的现货水平上。」把这句话摆进结论，读者自己会判断合理性。

### 检验二 · 多头自己的模型是否已埋周期顶

翻最乐观券商的预测表，看**最后一年**：

- 末年 EPS 增速骤降至个位数？
- 末年营收/利润转负增长？
- ROE 从 100%+ 掉回 50% 区间？

若是，说明连多头都不认为峰值可持续。这比任何看空报告都硬，因为它出自看多方自己的模型。

### 检验三 · 分歧度惩罚

计算同一预测年份的 EPS 最高/最低倍数、目标价最高/最低倍数。任一 >1.5x → 安全边际要求 **+10pp**（`inv-qarp-strategy` 规定）。极端周期股常见 2x 以上，此时必须叠加。

## 二、正常化盈利估值（替代 PE 分位）

周期股的 PE 历史分位没有判别力（亏损年 PE 为负或极大），**不要用分位数下结论**。改用：

```
可持续中周期净利 = 峰值年净利 × 30~40%
合理市值       = 可持续中周期净利 × 中周期合理 PE（8~10x）
安全边际       = (合理市值 − 当前市值) / 合理市值
```

30-40% 折算系数依据：商品化制造业跨周期平均利润率通常只有峰值的三分之一左右。若标的有真实产品壁垒（如 HBM 之于普通 DRAM），可上调至 40-50%，但必须先通过第三节的质量检验。

要求安全边际（QARP 表 + 分歧度惩罚）：

- 周期股/困境反转 ≥50%
- 高波动科技股 ≥40%
- 分歧度超阈值再 +10pp

**处理卖方目标价**：不参与事实裁决。若要引用，取**最低**目标价 ×0.85 作为参考上限。一个有力检查是：若「最保守券商的打折目标价 ≈ 今天股价」，则市场已把谨慎情形定价完毕，追高无剩余。

## 三、修正方向与增长质量（比绝对值更重要）

### 一阶导检验：连续上调 → 首次下调 = 体制转变

按日期排出每家券商的 TP / EPS 修正方向。绝对数字仍然巨大不代表安全，**导数变号才是信号**：

- 出现第 1 家下调 EPS → 观察级警告，写入打脸条件
- 出现第 2 家下调同一预测年 EPS → 视为逻辑恶化，触发放弃/减仓

同时看清下调的是哪个品类。周期链条里弹性最大的分项（如存储里的 NAND）总是最先掉头，它是领先指标。

### 增长质量：高壁垒产品收入占比

这是最容易被 EPS 数字掩盖的恶化。逐季追踪「高壁垒产品收入 / 总（或分部）收入」。

若总收入暴涨但高壁垒产品占比**下降**，说明增长来自商品化部分——这一轮增长是价格给的，不是壁垒给的，可持续性远低于 EPS 表面所示。该项恶化的权重应高于一次 EPS miss。

管理层若把占比下滑归因于「出货节奏」（临时性），要主动找是否有券商提出能力/意愿层面的替代解释（如「提价不如同行激进」）——后者不是时点问题。

## 四、反方覆盖强制要求

极端周期顶部有一个稳定规律：**卖方研报会 100% 一致看多，而股价在崩**。

1. 若库内该标的全部为 Buy/Outperform/OW，零看空、零下调评级 → 标注「反方覆盖缺口」，`knowledge_status` 最高只能给 `partial`
2. **禁止**因库内无看空而写「市场无重大担忧」。市场行为本身就是反方证据
3. 必须外部补齐：指数级/板块级实际价格行为（熔断、单日跌幅纪录、自峰值回撤%），以及卖方盲点类新闻
4. 把「卖方共识 vs 市场定价」的背离写成一节，逐条列出市场在定价什么

常见卖方盲点清单（存储/半导体）：

- 上游设备国产化（DUV/EUV 替代路径）——卖方往往只讨论终端客户是否采用国产芯片，漏掉设备端
- 全球拥挤交易的同步平仓（判别：看同板块海外标的是否同步暴跌；若日本/台湾同链条一起跌，则非单一市场事件）
- 本地市场机制放大器：单一个股杠杆 ETF、融资盘、程序化交易形成强制平仓螺旋
- 客户资本开支可持续性（尤其依赖融资的新兴客户）

## 五、工具与行为约束

### 禁用杠杆工具

极端周期股只用普通股或 ADR，不用 2 倍/单一个股杠杆 ETF。理由不是保守而是机制性的：本类崩盘的传导链条正是杠杆 ETF 与融资盘的强制平仓螺旋，杠杆工具会在最该持有的时点强制离场。若用户历史上持有过此类工具，在结论中显式点名并给出非杠杆替代。

### 行为陷阱识别：崩盘卖出 → 反弹买回

检查 `~/.hermes/memories/PORTFOLIO.md` 中该标的或其关联工具的处置日期，与历史价格对照。若在暴跌日附近清仓、数周后在反弹 20%+ 的位置询问买入，这是行动偏误 + 追涨杀跌形态，**必须在结论中直接点出**，并给出日期与涨跌幅对照。

用户要求条件单优先于主观判断、月最多 1 次操盘，因此结论应落在**触发条件**上，而不是「可以考虑买一点」。

### 组合层硬约束优先于个股结论

即使个股通过闸门，仍需检查：

- 现金 <5% → QARP 规则停止新建仓（无弹药时任何买入都是被动调仓）
- **同因子敞口穿透**：不看行业标签，看共同驱动因子。AI 硬件因子应把半导体 + 软件云 + 科技 ETF 合并计算，验证是否同向暴跌过
- 杠铃校验：进攻端已满载、防御端（现金）低于警戒线时，结构上不允许再加高 beta 资产
- 机会成本：与已持有同因子标的对比盈利可预测性与跨周期 FCF 质量，明确回答「是否优于现有持仓」

### 极端周期股 A+H IPO 的 PHIP 阶段门禁

当存储、航运、化工、资源等周期公司以 A+H 形式赴港上市时，先识别港交所文件版本：

- Application Proof 与 PHIP 中若发行价、发行量、股票代码、基石及上市日期仍显示 `[REDACTED]`，只能做条件化预判，不能给最终「打/不打」结论
- PHIP 阶段先提取周期位置、存货、经营现金流、债务和供应商集中度，再用最新 A 股价格建立「假设发行价—AH折价」条件表
- AH 折价不能机械锚定处于峰值盈利期的 A 股价格；应并列展示 trailing PE、峰值年化 PE 和第二节的正常化盈利估值
- 最终申购门槛必须等正式招股章程披露后，再结合发行价、基石质量、国际配售、孖展和招股期内最新 A 股 5 日均价重算
- 若利润爆发同时伴随存货、借款上升及经营现金流流出，标记「库存收益/营运资本驱动」，禁止把表观低 forward PE 当安全垫

## 六、输出约定

- **结论先行**：操作建议 → 3 条理由（按权重排序）→ 关键数据 → 详细分析
- 工具/数据缺口在第二节就交代清楚，说明后果与替代口径，不要藏在末尾
- 时间线用表格或按日期缩进列出，标明每次修正方向
- 证据矩阵列出：命题 / 事实基础 / 正方 / 反方 / 强度 / 流入哪个决策环节
- 结尾给**买入触发**与**放弃触发**两组条件，每条可被单一事实验证（可写成条件单）

## 七、常见陷阱

| 陷阱 | 后果 | 防范 |
|---|---|---|
| 用 forward PE 低当买入理由 | 在周期顶买入 | 先跑第一节三个检验 |
| 用 PE 历史分位判断周期股 | 分位被亏损年扭曲，无判别力 | 改用正常化盈利估值 |
| 把峰值 ROE 套「近3年均值>15%」闸门 | 周期股必然通过，闸门失效 | 明说这是峰值 ROE，并指出周期低谷年是否亏损 |
| 忽略 FCF/净利比 | 峰值利润全被 Capex 吃掉 | 单独核 FCF 收益率；峰值年常低至个位数 |
| 一次性收益混入可比净利 | 净利虚高（如出售股权收益） | 剔除后再算 PE，明确标注不可外推 |
| 库内无看空即认为无风险 | 在共识最一致处买在最高点 | 第四节强制反方补齐 |
| 把不同日期的预测拼成「当前共识」 | 掩盖修正方向 | 严格按日期排时间线 |
| 数据层脚本失败就跳过估值门禁 | 无锚定的主观结论 | 显式手工情景估值 + 标注 `upstream_failed` |

完整实战案例（数据、时间线、正常化测算、触发条件）见 `references/sk-hynix-2026-memory-supercycle.md`，可作为本纪律的填充模板。
