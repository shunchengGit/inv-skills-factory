# 股票价值与回报评估

预测的是条件成立时的经营结果与股东回报，不是保证股价。任意股票均可进入流程；不适用统一模型、证据不足或无法可靠估计时，结论必须是“无法可靠预测”，不能为了输出三行数字强填参数。

本技能负责可复核的回报设计、按年现金流IRR计算及个人目标比较，不另立买卖策略。研究与资本配置唯一框架仍是 `inv-qarp-strategy`；数据取 `inv-stock-data`；今天价值区间取 `inv-valuation-engine` 主估值，本技能不另建估值政策；已有判断与新判断统一取/写 `inv-portfolio-tracker` 受控台账。估值引擎三情景是期末归集简化年化，本技能补逐年现金流IRR、目标反推价与悲观底线，同一经营输入不得两边各调一套。

## 何时使用

- 用户问某股票未来持有期收益、悲观/中性/乐观年化、达到目标需要什么价格。
- 用户问当前安全边际、能否加仓，需把经营预测转成同口径回报；动作结论交QARP。
- 用户追问“怎么算的”：展示来源、经营桥、单位换算、现金流时序、公式和敏感性，不换模型偷改前提。
- 仅询问已算结果时复用有效模型，只更新价格与受影响参数；不每日全量研究。
- 不用于短期点位、涨跌天数、保证收益或替代券商真实成交核算。

## 前置上下文

1. 用户直接调用时加载QARP与数据/估值技能；由QARP或加减仓入口调用时只做本技能的回报计算并把结果交回，不再回调QARP。读当前profile的 `memories/USER.md`、`PORTFOLIO.md`、台账当前卡和audit；路径按实际Hermes home解析，不跨profile写入。
2. 收益目标、持有期和悲观底线每次动态解析：本次用户明确要求优先，其次最新USER；历史对话、示例JSON及测试数值均不得作为默认值。缺目标时先完成不依赖目标的情景预测，达标与反推价标待确认。临时目标不改长期USER，用户明确永久调整才更新。技能与脚本不硬编码个人收益率、仓位或现金规则。
3. 目标为区间时同时算下沿和上沿。悲观底线可为任意用户指定数值（如负收益容忍线）或税后无风险利率；后者须联网核验同币种同期限及税率适用性，缺失标待核，不用零或臆测替代。运行前显式列目标值、底线、来源及临时/长期作用域；目标变化只重算达标与反推价，不为迎合目标改经营情景或估值参数。
4. 持仓分析带入当前仓位和共同风险；现金只记账，不因现金低否决价值判断。新机会须与代表性现有持仓/暂缓比较，缺组合上下文拆开个股与组合结论。

## 双路径：价值在先，回报交叉检验

默认对任何标的同时运行两条路径：

- 路径A：经营与资本需求→估值引擎主估值→今天合理价值区间→当前价的估值折让→安全边际判断。所需缓冲按经济风险和误差解释，不统一打折，不把目标回报率当客观资本成本。
- 路径B：同一经营基准→持有期盈利/现金分配与退出价值→悲观/中性/乐观IRR→按动态目标反推最高买价。期限以本次要求或USER为准。
- 并列展示“价值路径是否有折让、回报路径是否达标、对误差是否稳健”；不能仅因一条路径好看就认定可买。两路共享经营、资本开支、稀释、币种和证券单位，期限/终值/折现目的不同须标明；同源两套算式不是独立证据。
- 冲突时不平均：定位增长、现金转换、资本投入、退出倍数、终值或折现率，给敏感性和不重估对照。A便宜而B回报低，查兑现期限与分配；B回报高而A不便宜，查是否依赖高增长或高终值。
- 一路无法可靠完成时仍保留该节，写明原因及另一路能支持的有限结论，不编价值区间，不把资料缺口当无限等待理由。

## 程序：先经营，后价格

1. 定义标的、证券类型、计价货币、报价来源/时点、持有期、税费口径。ADR、H/A股、拆股、摊薄股数、FX方向逐项核对；不把普通股EPS直接除ADR价格。
2. 找少数改变价值的变量，按知识库检索→原始财报/研报定位核验。事实、公司指引、卖方预测、自主假设分层。新财报后，财报前预测只用于预期差，不冒充更新模型；预期差以实际可得的一致预期或机构预测为基准，来源不足如实披露，不拿同比代替。
3. 按经济机制选模型，见 `references/model-selection.md`。悲观不是固定打八折，中性不照抄最乐观研报，乐观不靠无限PE扩张。每种情景给经营路径、资本需求、现金分配、退出估值与证伪条件；参数成组一致，不拼高EPS与最低capex。
4. 今天价值区间取估值引擎一主一辅；与持有期终值、目标买价分别命名。DCF贴现率是风险机会成本，不等同用户目标，不能为达标下调。显式展示终值占比与参数敏感性。安全边际与稳健性按 `references/margin-and-robustness.md`。
5. 主/辅冲突时定位现金转换、资本开支、退出倍数、汇率等变量，不平均出虚假共识。无法桥接的FCFF、净现金、租赁、SBC、归母/非控股权益不得自动算进可分配现金。未知分阻断项、可界定项、背景项，说明各自如何改变结论，不绕过QARP/台账门禁。
6. 为计算器准备证券单位的三情景终值与逐年股息；深度/推荐式分析另加 `no_rerating` 不重估对照。币种、ADR比例、稀释、经营桥由研究者先核验；计算器只算，不验证经济真实性。字段见 `templates/README.md`，先读 `templates/example.json`；示例不得改名套用或充当市场事实。
7. 运行 `python3 -B {baseDir}/scripts/forecast_returns.py --input <绝对JSON路径> --output json`。目标填 `target_cagr_range`，悲观底线填 `pessimistic_floor_rate` 并在 `pessimistic_floor_basis` 写来源。脚本只用标准库，不联网、不读USER/持仓、不写台账、不交易。
8. 读IRR与期末归集CAGR差异：IRR按每年净股息和期末净卖出，不默认再投资；年度间隔不是XIRR，非整年或不规则分配另按真实日期计算并说明。三情景不是概率，不给胜率、期望收益或置信区间。
9. 读 `max_buy_prices_for_target`（目标下/上沿价）、`target_buffers`（回报余量）与 `pessimistic_floor`（底线价、余量、是否通过）。选一至两个关键变量反推当前价达标所需EPS/现金/倍数/ROE并检验现实性。不同币种/期限、税前/税后不混比；缺税费/FX/底线口径时只能输出受限参考。
10. 对照QARP和用户实际约束做资本配置：中性达标但悲观失守时明确取舍，不输出“模型通过所以买”；研究未就绪不新增买入授权。旧提醒不是自动买线，不因成本价、怕错过或跌幅大推动交易。
11. 无实质变化引用旧卡；实质新预测/判断按tracker协议写v3卡并读回，保留模型、来源、日期及参数变动原因；不在观察表/档案/持仓重复维护判断，不新增定时任务。

## 输出契约

按问法控制长度，结论先行、纯文本：

[ 预测口径 ] 价格与报价日、证券/币种、持有期、IRR或简化CAGR、税费/分红/FX处理。
[ 安全边际 ] 必须单列，不能被收益表或“模型未完善”一句替代。①估值折让：今天价值区间、当前价与折让区间；不能可靠量化时写“估值折让暂不可可靠量化”，说明决定区间的变量与下一证据。②目标回报余量：中性相对目标下/上沿、悲观相对底线的百分点差，标为回报缓冲，不冒充估值折让。③稳健性结论：充足/有限/不足/待判断及依据；不能量化折让不等于没有缓冲，目标达标不等于估值便宜。即使无买卖结论也不得省略本节。
[ 三种情景 ] 悲观/中性/乐观年化、期末证券价格、累计净分红及每行关键经营/估值假设；深度分析另列不重估回报，说明是否依赖倍数上升。
[ 目标与价格 ] 本次目标与底线及来源；目标下/上沿最高买价、悲观底线价；当前价达标所需关键经营假设。
[ 驱动与反证 ] 少数经营变量、永久损失路径、最强反对理由、敏感性及替代机会；只列能改变结论的下一证据。
结尾固定“关键假设”“失效条件”。百分比一位小数、价格合理精度，不把两位小数伪装成经济精度。

只问“三种年化多少”时给三行加口径与主要限制；问“深度分析”再展开证据、经营桥、模型与组合。推荐式结论必须完成QARP，不以本技能绕过门禁。

## 必须避免的错误

- 安全边际=1−价格/今天内在价值；高点回撤、未来终值折让、上涨空间、目标回报买价是不同概念。无法可靠估值就写未证明，不强报精确值。
- DCF不把贴现现金与股息重复相加、不加回全部增长投资、不重复加现金及其利息；企业现金流配WACC/净债桥，股权现金流配股权回报要求。
- 不把税前模型与税后底线直接判通过，不给未知税率填零后宣称税后；税费为0须说明是假设。
- 悲观不等于最坏尾部；欺诈、违约、地缘中断、永久稀释单列尾部风险，不硬塞概率。
- 股价涨跌不认证经营假设；目标价无法由EPS/倍数/FX复算时先找桥，不臆造ADR溢价。
