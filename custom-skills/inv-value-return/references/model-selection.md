# 预测模型选择与个人适配

## 统一问题，不统一公式

所有公司都问：谁付钱、优势能否持续、增长要投入多少资本、现金归谁、当前价格下保守回报如何、什么证伪。不能因为用户说“任意股票”就给任何公司都强套EPS乘PE。

| 经济类型 | 主要预测桥 | 可用主估值 | 独立辅助检验 |
| --- | --- | --- | --- |
| 稳态现金型消费/平台 | 用户或销量×价格→利润→维护/增长投入→股东现金 | 正常化股权现金折现 | 盈利/分红回报、竞争与投入敏感性 |
| 科技制造/半导体 | 产能×利用率×结构/价格→良率/折旧→OCF−全部capex | 正常化现金或周期完整盈利 | EPS退出回报与现金转化，不用峰值低PE证明便宜 |
| 银行/保险 | 资产/保费→息差/信用/承保→资本充足→可分配利润 | PB-ROE、股息/剩余收益 | 资本约束及压力损失；不把客户存款当工业债务 |
| 商品周期/航运 | 供需与价格/成本→中周期利润→更新资本 | 正常化盈利/资产价值 | 完整周期现金、供给投放；不能外推现货峰值 |
| 地产/REIT | 出租率/租金→净经营收益→维护投入/融资到期 | NAV、可持续分配现金 | 利率/资产减值/再融资压力，卖资产非永续分红 |
| 多元控股 | 各业务现金、资产价值→母公司债务/税/费用 | 分部估值 | 合并现金与可变现性，避免重复计股权资产 |
| 亏损成长/生物科技 | 收入/单位经济→盈亏平衡→融资与稀释→每股归属 | 有证据的路径/SOTP或净资产 | 生存期、现金消耗、里程碑；缺证据输出无法可靠预测 |

## 三情景的建立

- 用少数联动变量产生结果，例如收入增速/正常利润率/capex与营运资本/每股稀释/退出估值，不一次堆十几个不可核参数。
- 悲观采用合理可发生的经营受压路径，不仅把退出PE降低；乐观同时写清实现条件和所需投入，中性不取卖方最高值。
- 券商一致只代表相似预期，不自动提高置信度；找共同失效因子，不能把不同年份不同现金定义平均。
- 预测期区分财年、自然年、季度，存托与本地普通股区分；退出倍数必须与退出期正常盈利一致。
- 分红/回购/净现金不能重复计入。EPS路径已经包含回购增厚时，不再把回购额当现金分红；稀释用未来每股结果反映。
- 通用计算器消费最终证券价格与逐年现金，不产生经营预测；unsupported经济模型不妨碍计算，但降低经济结论可用性。

## 个人特点的落实

先读取最新USER，不把本说明作为目标数值真源。对长期价值成长投资者，预测聚焦一至三年逻辑兑现，必要延长经营显式期解释价值；持有期与DCF期可不同，必须说明。

- 目标回报用经营与现金支撑，不依靠情绪修复/重回高点。
- 悲观底线按本次指示或最新USER解析，可为负收益容忍线或已核同币种同期限税后无风险；中性区间同时测下沿/上沿，避免只挑较低目标宣称全部达标。
- 更看重稳定与分红时，展示净股息贡献、现金转换、资本配置和永久损失，不只报乐观涨幅。
- 行动偏误/后悔厌恶的应对是证据触发与分批，不是禁止理性调仓；新增资金需要相对优势，成本价不参与未来回报。
- 缺现有持仓上下文先拆个股与组合层，现金不作价值否决；集中度和交易节奏由实时USER读取，不硬编码。

## 区分三种价格

1. 今天价值：未来全部可分配现金按适当风险机会成本折现，有估值误差；安全边际以此为分母。
2. 持有期终值：未来某日证券价格，配合期间现金才得到年化；不是今天价值。
3. 目标回报最高买价：给定情景现金流，按用户目标折现反推；不是另一个已认证内在价值或自动买单。

不得将用户目标直接替换成WACC/股权资本成本并声称得到唯一客观价值；可以另算目标回报价，但必须名称与目的分开。

## 案例教训（ADR半导体复盘）

- 同一经营假设下，期末归集年化与按年股息IRR不同，报告须标明用的是哪一个。
- DCF终值占比与贴现敏感性前置；把整数价写成两位小数不增加真实性。
- 基准年化达标不代表悲观底线通过，两者分别报告。
- ADR目标价须由盈利、倍数、汇率及证券比例复算，桥不明先保留未知。
- 不把“缺研究”当无限等待借口：定位会改变配置结论的经济未知，输出所需证据和结论敏感性。
