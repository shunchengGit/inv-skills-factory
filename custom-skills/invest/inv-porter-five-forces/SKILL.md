# Porter 五力分析

> 对指定行业或公司进行 Porter 五力竞争格局分析

## 用法

- `/porter_five_forces 福耀玻璃` — 分析福耀玻璃所在行业的竞争格局
- `/porter_five_forces 汽车玻璃行业` — 直接分析指定行业

## 执行流程

### 步骤 1：数据获取（如指定了具体公司）

如果用户指定了具体公司（而非仅行业名称），运行五力数据快照脚本：

```bash
uv run {baseDir}/scripts/five_forces_snapshot.py {股票代码} --output json
```

脚本一步获取以下数据：
- 公司画像（行业、板块、概况）→ 确定行业边界
- 关键财务（毛利率、净利率、ROE、收入增速等）→ 交叉验证五力结论
- 行业基准匹配（自动从 industry-benchmark.md 匹配）→ 评分起点参考
- 五力线索（从公司简介/新闻/公告中提取的关键词线索）→ 各力评分的事实依据
- 预评分（20 分制，基于行业基准+财务指标+事件关键词）→ 评分起点参考
- 同行业成分股（A 股）→ 评估竞争者数量与集中度
- 近期动态（新闻、公告）→ 辅助判断趋势变化

**评分体系统一说明**：本技能所有评分统一使用 20 分制（与 `scoring-standard.md` 和 `industry-benchmark.md` 一致）。分越高 = 公司在该维度的护城河越强、竞争力越稳固。脚本预评分与最终评分使用相同的 20 分制和方向，应参考预评分但可基于定性判断调整。

如果用户只指定行业名，跳过此步骤，基于行业知识分析。

### 步骤 2：确定分析边界

明确：
- 行业定义和范围（如"汽车玻璃"而非泛泛"汽车零部件"）
- 地域范围（全球 / 中国 / 特定区域）
- 价值链环节（上游原料 / 中游制造 / 下游渠道）

### 步骤 3：逐力分析

读取 `{baseDir}/references/porter-framework.md`，对每个力按以下结构分析：

#### 并行模式说明

**关键原则**：五力分析共享同一组公司数据，子代理各自搜索会导致重复劳动，反而更慢。

| Agent 能力 | 执行方式 |
|-----------|---------|
| 有子代理能力 | 主会话先运行 `five_forces_snapshot.py` 获取共享数据，然后把**数据快照 + 纯分析指令**派发给 5 个子代理。子代理只做推理，不搜索 |
| 无子代理能力 | 顺序执行五力分析，使用步骤 1 已获取的数据快照 |

**子代理任务模板**（仅派发给有子代理能力的 Agent）：
```
你是五力分析子代理，专门分析"{力名称}"这一力。

标的公司：{公司名称}（{股票代码}），{行业}

数据快照：
- 主营：{主营业务}
- 毛利率：{xx}%，净利率：{xx}%，ROE：{xx}%
- 预评分参考：{xx}/20（{置信度}）

行业背景知识：
- {从快照中提取的行业关键信息}

按以下结构分析，每个维度给 1-20 分（分越高 = 护城河越强/侵蚀威胁越低）：

| 维度 | 评分 | 依据 |
|------|------|------|
| {维度1} | ? | 具体事实 |
| {维度2} | ? | 具体事实 |
| {维度3} | ? | 具体事实 |

综合评分：XX/20
小结：1-2句话
```

#### 评分规则

每个力按 `scoring-standard.md` 的 20 分制评分。分越高 = 公司在该维度的护城河越强、竞争力越稳固（与侵蚀力方向相反）。

先对每个力的 3 个维度各打 1-20 分，取均值作为该力的综合评分：

| 力 | 维度1 | 维度2 | 维度3 |
|----|-------|-------|-------|
| 供应商议价力 | 供应商集中度 | 替代投入可用性 | 转换成本 |
| 买方议价力 | 买方集中度 | 产品差异化/转换成本 | 后向整合威胁 |
| 新进入者威胁 | 进入壁垒高度 | 资本/技术/政策门槛 | 报复可能性 |
| 替代品威胁 | 替代品性价比 | 替代品趋势增速 | 转换成本 |
| 行业内竞争 | 竞争者数量与集中度 | 行业增速与差异化 | 退出壁垒 |

**评分含义**（详见 `scoring-standard.md`）：
- 18-20：极强护城河，该维度几乎不存在侵蚀风险
- 14-17：较强护城河，侵蚀风险低
- 10-13：中等，存在一定侵蚀可能但可控
- 6-9：偏弱，侵蚀已较明显
- 1-5：护城河薄弱，该力严重侵蚀公司盈利

**评分方法**：
1. 参考 `scoring-standard.md` 中的分数区间和常见信号打分
2. 每个维度需引用具体事实或数据支撑，锚点仅作参考——若行业特性使某锚点不适用，可适当偏离并说明理由
3. 若步骤 1 获取了数据快照，优先使用快照中的客观数据（如财务指标、行业基准分），同时结合定性分析进行调整

### 步骤 4：交叉验证

#### 4a. 五力交互效应

审视五力之间的交互效应，修正初步结论：

- **供应商力 + 买方力**：双向挤压？行业利润被上下游同时侵蚀？
- **进入壁垒 + 竞争强度**：高壁垒是保护了在位者，还是加剧了内部竞争？
- **替代品 + 进入威胁**：替代品是否降低了进入壁垒？
- **买方力 + 竞争强度**：买方强势是否导致价格战？
- **退出壁垒 + 竞争强度**：高退出壁垒是否导致产能过剩？

如发现交互效应显著，调整相关力的评分（±2-5分），并说明调整理由。

#### 4b. 财务数据交叉验证

按 framework 文档中的"财务数据交叉验证规则"逐条检查：

1. 毛利率是否与供应商议价力 + 买方议价力的评分组合一致？
2. 净利率是否与整体五力格局一致？
3. ROE 是否与行业吸引力评分一致？
4. 收入增速是否与买方议价力和同业竞争的评分一致？
5. 毛利率-净利率差是否得到合理解释？
6. 各力评分是否与行业基准方向一致？

若任何一条出现矛盾，调整评分或补充解释，并在报告的"交叉验证"部分明确标注。

### 步骤 5：综合判断

输出：

1. **行业吸引力评分**：1-10（1=极无吸引力，10=极有吸引力）
   - 计算方式：5个力的 20 分制评分取加权平均，按 `(均分 / 20) * 10` 转换为 1-10 标度
   - 各力评分越高（护城河越强）→ 行业吸引力越高
2. **对目标公司的含义**：基于五力分析，该公司的竞争地位如何？哪些力对它有利/不利？
3. **时间维度**：当前格局 vs 3-5年趋势变化（哪些力在增强/减弱？驱动因素是什么？）

## 注意事项

- 所有五力维度评分统一使用 20 分制，分越高 = 护城河越强（详见 `scoring-standard.md`）
- 分析应基于事实和数据，避免泛泛而谈
- 如果某力缺乏足够信息，明确标注"信息不足"而非臆测
- 行业边界定义对分析结果影响极大，需谨慎界定
- 五力分析是静态快照，行业格局持续变化，需关注趋势
