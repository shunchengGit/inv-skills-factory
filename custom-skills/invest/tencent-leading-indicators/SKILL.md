# 腾讯前置指标分析

> 版本 1.1.0 — 3/6 指标脚本自动获取，3/6 搜索补充；新增AI进展定性评估

## 用法

- `/tencent_indicators` — 完整分析：获取数据 → 搜索补充 → 逐指标评分 → 综合判断 → 输出报告
- `/tencent_indicators_data` — 仅获取数据快照，不做分析

## 执行流程

### /tencent_indicators（完整分析）

1. **获取数据快照**
   ```bash
   uv run {baseDir}/scripts/tencent_indicators.py
   ```
   脚本自动获取：社零增速（东方财富宏观API）、王者/和平畅销榜（App Store RSS）、港股通南向（akshare）。
   游戏版号/视频号时长/微信支付笔数 标记为 agent_required。

2. **读取传导机制框架**
   读取 `{baseDir}/references/indicator-framework.md`

3. **搜索补充 agent_required 指标**
   快照中每个 agent_required 指标都附带 `search_hint`，按提示搜索：

   - **游戏版号发放**：搜索"国家新闻出版署 游戏版号 2026年月度 审批信息"
   - **视频号使用时长**：搜索"视频号 人均使用时长 2025 2026"或"腾讯业绩会 视频号 增长"
   - **微信支付笔数**：搜索"腾讯 微信支付 商业支付笔数 增速"或"腾讯财报 金融科技"

   **推荐方式**：并行搜索补充 agent_required 指标，搜索结果返回后按 `scoring_guide` 评分。

4. **逐指标分析**
   对每个指标输出：**信号**（偏多/中性/偏空）、**评分**（-1.0 到 +1.0）、**理由**（1-2句话引用数据）

   分析依据：
   - `scoring_guide`：量化评分区间（优先参考）
   - `direction` 和 `transmission_summary`：传导方向和机制
   - `threshold`：关键阈值（超越=强信号）

   **方向规则**：
   - `policy`：版号↑→政策宽松→利好→偏多
   - `revenue`：畅销榜排名靠前→流水稳定→利好→偏多
   - `consumption`：社零↑→广告/支付↑→利好→偏多
   - `growth`：时长↑→广告库存↑→利好→偏多
   - `capital_flow`：净流入↑→买盘支撑→利好→偏多

5. **综合判断**
   - 按各指标 `weight` 加权汇总评分
   - 考虑指标间交互效应
   - 输出综合信号（偏多/中性/偏空）、置信度（高/中/低）、一句话理由

6. **按输出模板格式输出报告**

### /tencent_indicators_data（仅数据）

```bash
uv run {baseDir}/scripts/tencent_indicators.py --output text
```

## AI 进展定性评估（每次分析必加）

腾讯AI投入已从"技术储备"进入"赋能核心业务+产品化"阶段，对投资逻辑影响日益显著。每次前置指标分析报告末尾应增加AI进展定性评估。

### AI关键观察点

| 维度 | 指标 | 数据来源 | 信号判断 |
|------|------|----------|----------|
| 自研模型 | Hy系列模型性能排名、OpenRouter token消耗量 | 财报/业绩会 | 排名上升→技术竞争力增强→偏多 |
| AI产品化 | WorkBuddy DAU、元宝MAU、CodeBuddy用户数 | 财报/业绩会 | DAU持续增长→产品PMF验证→偏多 |
| AI赋能核心业务 | AIM+赋能广告投放比例、AI推荐驱动时长增速 | 财报分部数据 | 赋能比例提升→护城河加固→偏多 |
| AI投入成本 | CapEx绝对值及增速、AI产品亏损额 | 财报 | CapEx增速>收入增速→盈利稀释→偏空 |
| AI收入贡献 | AI原生产品收入、云AI服务收入 | 财报 | 收入>亏损→拐点→强偏多 |

### AI进展对估值的影响框架

- **投入期**（当前）：AI新产品亏损拖累非IFRS盈利，CapEx攀升压制ROE和FCF → 估值承压但可接受（Forward PE已反映）
- **赋能期**：AI提升核心业务效率（广告+20%、视频号时长+20%）→ 收入增速超成本增速 → 估值修复
- **变现期**：AI原生产品实现盈亏平衡 → 新增长曲线 → 估值重估
