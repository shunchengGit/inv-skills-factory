# 报告输出规范（公众号/可发表格式）

当用户要求将分析结论整理为**公众号文章、研报或任何可发表格式**时，遵循以下规范：

## 1. 先规划结构，再动笔
不要直接输出。先向用户确认或自行确定整体结构，确保逻辑主线清晰：
- **推荐主线**：为什么现在要看 → 值不值得买 → 现在贵不贵 → 怎么操作
- 每个部分只回答一个问题，不跳跃、不重复
- 用表格呈现对比数据，用段落叙述逻辑判断

## 2. 突出时效性
- 开篇明确标注**数据时点**（股价日期、财报日期、研报日期）
- 用"5月最新变化""4月底密集研报"等时间锚点建立紧迫感
- 强调"核心矛盾"：业绩在加速 vs 股价冲新高、大行在看多 vs 位置在高位

## 3. 去除个人化表述
- **禁止**："我的建仓纪律""我愿意持有""我更喜欢""我的判断是"
- **改为**："当前位置适合观望""21x的PE值得持有""建议分2-3批建仓"
- 报告应对读者负责，而非表达作者个人偏好

## 4. 估值与操作分离
- **估值判断**回答"值不值得买"（合理/低估/高估）
- **操作判断**回答"什么时候买/买多少"（价格区间、仓位、批次）
- 两者可能不一致：合理偏低 ≠ 立即重仓，需解释位置风险和时间窗口
- **必须补充plan B**：如果等不到理想价位怎么办？设时间窗口+价格条件作为触发机制

## 5. 精简冗余
- 同一数据只出现一次。盈利指标、估值指标不要既在表格里又在段落里复述
- Porter五力等分析框架给出总分+各维度一句话结论即可，不必每个维度展开三段
- 卖方研报交叉验证：一张表展示一致预期，3个编号要点列出分歧，无需展开论述

## 6. 数据来源透明
- 末尾单列"数据来源"，明确标注：实时行情来源、财务数据来源、研报来源（券商+日期+页数）、网络增量来源
- 注明"卖方研报构成重要参考但不代表独立估值结论"
- 附免责
