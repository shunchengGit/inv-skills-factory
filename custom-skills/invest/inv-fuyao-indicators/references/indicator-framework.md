# 福耀玻璃前置指标逻辑框架

## 各指标对福耀玻璃的传导机制

### 纯碱价格 → 成本端

纯碱（碳酸钠）是浮法玻璃的核心原材料，约占玻璃生产成本的20-25%。福耀玻璃作为汽车玻璃龙头，年产能超1亿片，纯碱价格波动直接影响毛利率。

- 传导路径：纯碱涨价 → 浮法玻璃成本上升 → 汽车玻璃成本上升 → 毛利率承压
- 时滞：约1-2个月（库存缓冲+定价周期）
- 弹性：纯碱价格每变动10%，约影响福耀毛利率0.5-1个百分点

### 天然气价格 → 成本端

天然气是玻璃熔炉的主要燃料，约占生产成本的15-20%。福耀国内工厂使用国内天然气，海外工厂使用当地能源。

- 传导路径：天然气涨价 → 熔炉燃料成本上升 → 生产成本上升 → 毛利率承压
- 时滞：约1-3个月（长协价格调整周期）
- 注意：NYMEX天然气反映国际价格，与国内天然气价格存在差异，但趋势高度相关

### USD/CNY汇率 → 收入端

福耀玻璃海外收入占比约40%（北美+欧洲+亚太），以美元结算为主。人民币贬值直接增厚海外收入的人民币折算值。

- 传导路径：人民币贬值 → 海外收入折算增加 → 营收/利润增厚
- 时滞：当季度即可体现
- 弹性：人民币每贬值1%，约增厚利润1.5-2个百分点（考虑自然对冲后的净敞口）

### 中国汽车销量 → 收入端

中国是福耀最大的单一市场（约占50%+），汽车销量直接决定OEM配套需求。新能源车单车玻璃面积更大（天幕、全景玻璃），新能源渗透率提升是结构性利好。

- 传导路径：汽车销量增长 → OEM配套需求增加 → 营收增长
- 时滞：约1-2个月（从整车排产到零部件交付）
- 结构性因素：新能源渗透率 > 单纯销量总量

## 权重依据

| 指标 | 权重 | 依据 |
|------|------|------|
| 纯碱 | 20% | 成本端最大变量，价格波动大 |
| 天然气 | 12% | 成本端次要变量，波动相对温和 |
| USD/CNY | 18% | 海外收入占比高，汇率敏感度大 |
| 汽车销量(中国) | 18% | 收入端核心驱动，但月度数据更新慢（CPCA Playwright） |
| 集运指数(欧线) | 12% | 反映海运成本，间接影响出口利润 |
| 新能源渗透率 | 5% | 结构性利好参考，单车玻璃面积更大 |
| 美国汽车销量 | 10% | 新增：FRED TOTALSA，免费CSV，反映美国OE需求（~30%海外收入） |
| 欧洲汽车销量 | 5% | 新增：ACEA Agent搜索，无稳定免费API |

## 评分流程

1. 读取 JSON 快照，获取所有指标的实时数据、趋势、分位、scoring_guide
2. 对每个指标独立评分（-1.0 到 +1.0），**优先参考 scoring_guide 中的量化区间**
3. 按权重加权汇总。`scoring_guide` 提供的区间是参考基准，Agent 可根据波动警告、指标交互微调
4. 考虑指标间交互效应：
   - 人民币贬值 + 运价下跌 = 出口利润叠加利好（可适当上调综合评分）
   - 纯碱下跌 + 天然气下跌 = 成本端双重利好（可适当上调综合评分）
   - 汽车销量低迷 + 渗透率上升 = 总量弱但结构好（抵消效应）
5. 输出综合信号、加权评分、置信度

## 新增指标传导机制

### 美国汽车销量 → 海外收入端（v3.1 新增）

美国是福耀第二大单一市场，收入占比约 30-35%。美国汽车销量直接影响福耀美国工厂的 OE 需求。

- 传导路径：美国汽车销量↑ → 美国 OEM 产量↑ → 福耀美国工厂出货量↑ → 海外营收↑
- 时滞：约 1-2 个月（从整车排产到零部件交付）
- 数据来源：FRED TOTALSA（圣路易斯联储，免费 CSV 下载，无需 API Key）
- TOTALSA = Total Vehicle Sales，百万辆（SAAR 季调年化）
- 弹性：美国销量每变动 1M（100万辆），约影响福耀美国收入 3-5 个百分点
- 评分参考：
  - SAAR > 17M → +0.5~+0.7（美国市场强劲）
  - SAAR 16-17M → +0.2~+0.4（健康）
  - SAAR 15-16M → 0~+0.1（温和）
  - SAAR 14-15M → -0.2~-0.4（偏弱）
  - SAAR < 14M → -0.5~-0.7（萎缩）
- 注意：FRED 国内访问可能较慢（走美国 CDN），脚本设置了 30s 超时 + 3 次重试

### 欧洲汽车销量 → 海外收入端（v3.1 新增）

福耀在欧洲有德国、俄罗斯等工厂，服务欧洲车企。欧洲新车注册量反映欧洲 OE 需求。

- 传导路径：欧洲新车注册↑ → 欧洲 OEM 产量↑ → 福耀欧洲工厂出货量↑ → 海外营收↑
- 时滞：约 1-2 个月
- 数据来源：ACEA（欧洲汽车制造商协会）月度新闻稿，无稳定免费 API
- 当前方案：搜索 "ACEA new car registrations 2026" 获取最新数据
- 评分参考：同比 > 8% = +0.4~+0.6；同比 -8~-3% = -0.2~-0.4
- 替代方案考量：Eurostat 有 `road_eqr_carm` 数据集但 API 端点不稳定，FRED 个别国家系列（如德国）可用但无 EU 汇总

### 集运指数(欧线) → 收入端

CCFI综合指数反映中国出口集装箱运价，但东方财富无直接API。使用集运指数(欧线)期货(EC)作为替代——EC期货与CCFI走势高度相关，且是期货数据更及时。

- 传导路径：运价下跌 → 海运成本降低 → 出口利润提升 → 利好福耀海外业务
- 注意：EC期货反映欧线运价，与CCFI全航线指数有差异，但趋势一致
- 时滞：约1-2个月

### 新能源车渗透率 → 收入端

新能源车单车玻璃面积显著大于传统燃油车（天幕玻璃、全景天窗等），渗透率提升是结构性利好。

- 传导路径：渗透率提升 → 单车玻璃面积/价值增长 → 福耀ASP提升
- 数据来源：与汽车销量一起从乘联会页面解析
- 评分逻辑：渗透率绝对水平(>45%偏多，<30%偏空) + 近3月变化趋势
