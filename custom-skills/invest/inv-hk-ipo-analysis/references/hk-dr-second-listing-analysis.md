# 港股 DR/HDR 第二上市分析框架

适用场景：港股发行预托证券(HDR/DR)，标的为已在其他市场（印尼IDX、美股、新加坡等）首发上市的公司。**估值逻辑与H股新股完全不同**。

## 识别 DR/HDR 上市的信号

招股书或公告中出现以下任一信号即按本框架处理：

- 股票名称含 "-DRS" / "-HDR" / "-DR" 后缀
- 招股书首页/封面写"預託證券"、"Depositary Receipts"、"Hong Kong Depositary Receipts"
- 发行结构写"每份HDR代表X股普通股"（X通常是10或100）
- 保荐人含外资行 (UBS / Morgan Stanley / Goldman) + 中资行的组合
- 公司主体注册地不是开曼/BVI，而是印尼/泰国/越南等本地（PT XXX Tbk、bhd等）
- "现有股东出售股份"占比100%或绝大多数（旧股转让而非公司发新股集资）

## 与H股新股的本质区别

| 维度 | H股新股 | DR/HDR第二上市 |
|------|---------|---------------|
| 集资归属 | 公司收钱（用于业务扩张/研发/还债） | 全部或大部分归售股股东（公司不收钱） |
| 流通盘 | 全部新股 = 全部公开市场流通 | 仅占总股本5-15%（其余在母市场） |
| 估值锚 | 同行PE/PS、绝对估值 | **母股现价折算** |
| 减持压力 | 基石6个月、控股股东12个月 | 母市场无禁售，理论上随时套利 |
| MSCI风险 | 通常无 | 母国可能被MSCI从新兴市场降为前沿，触发指数基金抛售 |
| 套利机制 | 无 | DR vs 母股可双向兑换，存在折让收敛逻辑 |

## 母股折让计算（核心估值步骤）

这是 DR/HDR 分析的**第一步**，决定整个判断框架。

### 步骤

```
1. 获取母股现价（YYYY-MM-DD 当日收盘）
   - 数据源优先级：stockanalysis.com > Yahoo Finance > Investing.com
   - 印尼股：stockanalysis.com/idx/{TICKER}
   - 美股：stockanalysis.com/stocks/{ticker}

2. 获取汇率（中间价，非买卖价）
   - 1 HKD = X 本币（IDR / USD / SGD ...）
   - 数据源：xe.com / 招股书"匯率"章节通常列了LPD(最後實際可行日期)汇率

3. 折算母股价格至港元
   母股价(港元) = 母股价(本币) / 汇率

4. 计算HDR隐含价值
   HDR隐含价(港元) = 母股价(港元) × (每份HDR对应的母股数)
   常见比例：1 HDR = 10 母股 / 1 HDR = 50 母股 / 1 HDR = 100 母股

5. 计算折让幅度
   折让 = 1 - 招股价 / HDR隐含价
```

### 实例（Merdeka Gold 6228.HK，2026-06-21）

```
母股 EMAS.JK 现价：7,325 IDR
汇率：1 HKD ≈ 2,073 IDR
母股价折港元：7,325 / 2,073 = 3.534 HKD/股
每份HDR = 10股
HDR隐含价值：3.534 × 10 = 35.34 HKD
招股价：26.60 HKD
折让幅度：1 - 26.60 / 35.34 = 24.7%
```

### 折让水平的解读

| 折让范围 | 解读 | 操作含义 |
|---------|------|---------|
| 0-5% | 折让微薄 | 无安全边际，纯赌情绪，慎入 |
| 5-15% | 正常DR结构性折让 | 中性，看其他因素 |
| 15-25% | 显著折让 | 有套利空间，**但需查折让原因**：流动性差/MSCI风险/汇率波动？ |
| >25% | 异常折让 | 极强安全边际，或存在重大未披露风险，**必须深查** |

**关键陷阱**：折让幅度的"漂移"。LPD（最後實際可行日期）当天折让可能只有10%，但招股期间母股继续上涨，实际开盘前折让可能扩大到20%+。**必须用招股截止日前1-2天的母股价重算**，不能直接引用招股书数字。

## 旧股转让的财务含义

DR/HDR 上市常伴随"全部旧股"或"主要为旧股"——必须查清谁在减持、为什么减持。

### 查询位置

- 招股书"出售股東"章节（通常在200-300页之间）
- 查关键词：售股股東、現有股東、Selling Shareholders、減持

### 必须列出的数据点

```
| 售股股东 | 身份 | 减持股数 | 占总股本% | 减持后剩余% |
|---------|------|----------|----------|------------|
| XXX | 控股股东 | ... | ... | ... |
| YYY | 董事Z | ... | ... | ... |
```

### 红旗信号

- 公司高管/创始人在第二上市中大幅减持（>5%总股本）→ 失去信心或个人套现需求
- 战略投资者（PE/VC基金）退出 → 正常但需评估抛压时间表
- 母市场最近1年股价大涨后才赴港发DR → "高位接盘"嫌疑
- **全部旧股转让 + 孖展未足额**（双重信号）→ 极强卖出信号。"老股东集体套现+散户用脚投票"组合下，首日大概率开盘即跌，绝对不申购

## 流动性结构陷阱

DR/HDR 的港股流通盘很小（典型5-10%），意味着：

1. **首日大涨大跌都不稀奇** → 不可用同行新股波动率推算
2. **基石占比看似很高但意义不同** → 50%基石锁了的也只是港股那10%，对整个公司股权毫无影响力
3. **港股价格被母股牵引** → 母股大跌时港股很难独立走强
4. **港股折让若长期不收敛** → 因为机构套利成本高（DR/母股转换有费用和时间差，零售投资者无法操作）

## MSCI 重分类风险（仅东南亚/前沿市场）

印尼、菲律宾、越南、巴基斯坦等定期面临 MSCI 评级讨论：

- **从新兴市场降为前沿市场** → 被动指数基金需在数月内抛售全部相关持仓
- MSCI 公布时间：通常 6 月年度审议、11 月半年审议
- 查询路径：MSCI官网 Index Review 公告 + 当地财经媒体

如招股期撞上 MSCI 公告窗口（如 6/18-23），需在风险段落明确标注。

## 综合决策模板（DR/HDR 专用）

```
## DR/HDR 打新分析：[公司名]（[港股代码] / [母股代码]）

### 关键数据
- 招股价：XX HKD | 入场费：XX HKD
- 每份HDR = X 母股
- 母股现价：XX [本币]（截至 YYYY-MM-DD）
- 汇率：1 HKD = X [本币]
- HDR 隐含价：XX HKD
- **当前折让幅度：XX%**
- 港股流通占比：X.X% 总股本
- 集资性质：[全部旧股 / X%旧股+Y%新股]

### 折让原因分析
- 结构性折让（常态5-15%）：X%
- 流动性折价：X%
- MSCI重分类风险：X%
- 其他特殊原因：...

### 减持评估
- 主要售股股东：...
- 关键人物减持：...

### 操作建议
- 申购档位：[现金1手轻仓博收敛 / 1-2手 / 不申购]
- 首日策略：
  - 若高开 >隐含折让的50%（即收敛过半）→ 了结
  - 若低开破发 → 母股价仍在则可加仓（折让进一步扩大）
- 持有期：暗盘+首日，不建议长持（DR结构性折让常态存在）
```
