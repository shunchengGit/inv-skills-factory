# 网上获取官方招股书：核验与入库清单

## 来源优先级

1. 交易所正式招股章程、上市文件或最终 Prospectus
2. 交易所聆讯后资料集（PHIP）或申请版本
3. 公司官网投资者关系页面
4. 可信镜像，仅用于官方链接暂时不可达时

搜索引擎只用于定位。最终引用和归档应尽量回到交易所、监管机构或公司官方域名。

## 文件身份核验

下载后逐项确认：

- HTTP 200，响应类型为 PDF，文件以 `%PDF` 开头
- PDF 可打开，页数合理，首页公司中英文名与目标一致
- 最终版通常有股票代码、发行股数、公开发售/国际发售安排、最高价或定价
- PHIP/申请版本会标注 draft、incomplete、subject to change，并以 `[REDACTED]`/`[编纂]` 隐去发行条款
- 法律意见书、备案通知、监管批复、券商梳理稿不是招股书，即使标题包含“首次公开发行”或搜索结果紧邻正式文件

若最终版与PHIP同时存在，默认归档最终版；只有最终版尚未发布时才使用PHIP，并在标题和正文明确“申请版本/草稿”。

## 长篇招股书抽取顺序

先读以下章节，不要直接把全文灌入会话：

1. 首页与发行安排
2. Summary / 概要
3. Key operating and financial metrics
4. Consolidated results / 现金流与资产负债表
5. Risk Factors
6. History、股权结构、WVR与创始人控制权
7. 募资用途、股息政策和基石投资者（如有）

可先用PDF文本工具生成临时全文，再按关键词定向读取。条目至少覆盖：业务模式、收入与增速、经营利润率、净利润质量、客户/订单、区域结构、主要风险、治理结构和后续跟踪指标。

## 会计口径提醒

IPO前可转换可赎回优先股的公允价值变动可能显著放大或压低账面净利润。若存在此项：

- 同时列示经营利润、经营利润率与账面净利润
- 解释净利润变化中的非经营性部分
- 不把账面亏损直接等同于主营亏损，也不忽略经营利润率真实下滑

## 完成验收

只有以下全部满足才能称“已入库”：

- 原始PDF在 `res/{target}/`
- OKF条目正文合格且引用该PDF
- 至少2个真实存在的关联
- `entries/index.md` 可检索
- `dead_links=0`、`orphans=0`、`no_cross_refs=0`
- `pdf_no_entry=0`、`pdf_resource_missing=0`
- Git push成功
