# 财报后多机构研报：版本归并与观点比较

适用：下载同公司多份业绩后报告入库，随后用户问“分别说了啥”。

## 身份和覆盖

1. 截图的Date、Available、文件名日期、PDF正式日期分别记录；以PDF日期作为条目时间，解释日期差异而非误判缺件。
2. 同名同日同页数的截图行只说明列表层重复；没有文件哈希不能宣布附件完全相同。
3. H/A与H版可能核心正文相同，但前者独有A股估值、目标价或披露。核验报告编号、首页、估值页和差异页；保留含独有信息的版本，可共用一条知识记录并引用全部PDF。
4. 平台显示H股标题或A股ticker，不决定实际覆盖范围；双市场报告的A/H评级、目标价、货币均需提取。

## 入库必须保留的四条轴线

- 实际与预期：收入、经营利润、归母净利、毛利率逐项对照。标题“核心盈利超预期”可能同时伴随收入和归母低于预期；不得摘要成“财报全面超预期”。表格已有偏差可直接引用，自己计算须工具执行并标口径。
- 经营与一次性：关税退款、汇兑、保险赔付分别列出。毛利率的报告值和剔除一次性值并列；分部利润、营业利润、调整经营利润、利润总额不可拼接。
- 预测修订：记录每一预测年旧EPS→新EPS、销量假设及调整原因，优先保留原文清晰财务表。价格图上的重叠文字/坐标不可当预测值，必要时看原图。
- 估值修订：记录目标价变化、PE/DCF方法、估值基期、关键参数。盈利下修同时目标价上调可能来自滚动至下一年度，并非基本面转好；目标价不变也不表示盈利未变。

## 回答“分别说了啥”的结构

1. 先给共同叙事和核心分歧，避免逐段翻译。
2. 每家依次讲：最关注什么→实际/预期差→盈利如何修订→评级/目标价如何变化及原因→一句通俗归纳。
3. 用小表并列同口径2026E/2027E等EPS、A或H目标价、评级；不同币种明确标注，不混用两地目标价。
4. 如果EPS预测相近而目标价差异很大，定位估值倍数、折现率和估值基期分歧，不简单平均目标价充当公允价值。
5. 同时检查现金流预测是否真的一致：逐家保留经营现金流、现金资本开支、营运资金假设、净债务定义及FCF/FCFF标签。EPS相近但扩产投入与回款假设不同，仍可造成显著价值差异；未调平口径前不可平均FCF或直接将FCFF视为股东可分配现金。
6. 对周期恢复与汇兑反转，把下一年恢复增速与长期结构性增速分开；低基数Forward PEG只能作辅助，不能替代正常化盈利与现金流核验。
7. 最后提炼可观察的后续指标，不把报告解读自动升级为用户调仓建议；用户要求买卖决策时另走QARP门禁。

## 日期与时间线

新的财报后预测优先于财报前预测用于当前估值；历史预测保留作预期差和观点漂移证据，不覆盖旧研究。明确报告价格锚非实时行情。数量汇报分为PDF版本数、独立观点/机构数、知识条目数及实际废纸篓移动数。
