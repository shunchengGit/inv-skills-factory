# 问题驱动检索与深度探索

## 范围与边界

L1/L2/L3 分别描述候选定位、命题探索、专题综合；不是默认最低深度或投资就绪等级。任务遵循 QARP：行情刷新不研究，事件增量只差分，新增资本与换仓完成四问、完整情景及代表性替代比较，不重做全组合或大矩阵。

下游只读：`/km_search` 与 `km_import read`。候选 Synthesis、待入库资料交 curator 主流程；不得自行 store/res、刷新索引或版本递增。

## 按重要未知检索

1. 先明确命题、影响判断的未知与可改变结论的证据，接续已有有效研究。
2. 读 `entries/index.md` 定位候选；用标的中文/英文/代码或关键变量搜索，按召回需要扩词，不设角度或条目数量。
3. 读取相关正文与 frontmatter，按命题需要使用关联链、标签导航、反向回链和时间线；无需为“完成”遍历全库或固定链层。图谱维护能力保留。
4. 官方原始事实回原文并校验日期、币种、单位、会计口径与期间；预测/因果检验反证、不同解释和敏感性；重大疑点按需独立验证。同源转载不算独立，摘要不冒充核验。
5. `km_import.py read --file <PDF绝对路径> --pages edges` 只读首尾页，可识别报告但不足以核验中段数字；关键表格用 `--pages first-n --first-n <页数>` 或定位相关正文。记录实际读到的路径/URL、页码/表格与数值，不能只读封面称已核验。

## 命题时效

历史实际值与原始事实可长期回溯，确认所属期间、口径及后续修订；经营机制判断检查后续反证；价格、预测、指引按对应时点/预测期及新事件确认。旧文不因超过 183 天自动不可用，新文不自动正确。维护用 aging/stale 预警不是投资证据失效或删除指令；实际失效与恢复遵循 tracker 协议及 audit，不猜字段。

## 完成与缺口

说明命题、原文定位、实际核验/有效复用、反证、冲突及重要未知的结论影响。事件只输出新增/重核/未变/未知差分，基准引用接续；完整研究须实际支持四问与情景回报，不用检索角度、关联数量或 L 等级凑就绪。

知识库覆盖不足时写“哪个重要命题缺证据、已有来源及期间、对判断的影响、下一核验路径”。重要未知未处理则继续研究，不把缺条目、无关联或来源单一机械当作买卖理由。维护中的入库质量、索引、标签、反链与图谱由 curator 主流程负责。
