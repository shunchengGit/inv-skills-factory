# 研报身份识别与标题变体去重

用于研究平台截图对账、判断“某份报告是否已入库”，避免把界面简写或覆盖公司列表变化误当成不同报告。

## 判定顺序

1. 读取候选PDF首页，提取正式标题、发布日期、机构、覆盖市场、页数和报告编号（如有）。平台短标题、截断标题、H/H-A标签仅作为检索线索。
2. 比对资源哈希。首页正式标题、日期、机构一致且哈希相同，即使平台展示标题或公司列表不同，也认定为同一报告，不重复导入。
3. 标题相近但哈希不同时，继续核对页数、作者、目录和正文覆盖范围，区分完整版、摘要版、修订版或真正独立报告。
4. 回答“是否在库”时分两层：
   - 原始PDF是否已归档；
   - OKF条目是否完整覆盖报告中的标的和论点。
   PDF存在但条目遗漏部分覆盖对象，应表述为“已归档、条目提取不完整”，不是“缺报告”。

## 截图与附件对账

对每一行记录：`界面可见标题｜日期｜机构｜页数｜PDF首页正式标题｜哈希｜身份结论｜PDF归档｜entry状态`。只有完成身份归并后，才能确定用户所说的N份中实际有多少份独立报告。

## 验证

- 搜索 `res/index.md` 和 `entries/*.md` 时，同时使用正式标题、机构、日期、ticker和报告编号。
- 新附件归档前运行重复检查；归档后确认PDF-entry配对、索引可检索及Git push成功。
