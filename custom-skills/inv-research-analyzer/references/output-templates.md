# 研报输出模板

## 结构化输出模板（被下游技能调用时）

```markdown
## 研报结构化摘要：{TICKER}

### 元信息
- 标的：{代码} {名称}
- 覆盖研报数：N 篇（{最早} ~ {最晚}）
- 时效性：fresh / aging / stale

### 共识观点（2-3 条）
1. …

### 分歧观点（1-2 条）
1. …

### 评级与目标价区间
| 券商 | 日期 | 评级 | 目标价 |
|------|------|------|--------|

### 盈利预测区间
| 指标 | 年份 | 区间 | 来源 |
|------|------|------|------|

### 核心风险
1. …

### 隐含假设与失效条件
1. …

### 与五力/估值的交叉验证点
- 供下游技能引用的具体验证点
```

## Markdown 输出模板（用户直接使用时）

```markdown
# 【标的】研报梳理（本地 PDF）
## 一、覆盖文件清单
## 二、分报告摘要（逐篇，宜短）
## 三、综合观点（共识 / 分歧 / 预测区间 / 隐含假设）
## 四、局限说明
## 五、待核实项
```
