# 波特五力评分标准细则

默认每个维度 20 分，总分 100 分，分数越高代表公司竞争力越强、护城河越稳固。

## 使用原则

### 评分前先回答三个问题

1. 公司的核心产品或服务是什么
2. 公司所处的细分行业是什么
3. 竞争优势主要来自规模、品牌、技术、渠道、成本，还是政策与认证

### 评分时的统一要求

- 每个维度至少给出 2 条事实依据
- 尽量使用“公司事实 + 行业事实”组合判断
- 如果证据不足，结构化预评分必须为 `null`，不得用中性默认分掩盖缺口；可继续外部定性研究并补证据
- 18 分以上和 5 分以下都属于强结论，必须有明确证据支撑

### 常用证据线索

- 市场份额、CR3/CR5、客户或供应商集中度
- 毛利率、净利率、价格传导能力
- 认证壁垒、资本开支、研发投入、产能爬坡周期
- 替代技术路径、行业价格战、渠道控制力、品牌溢价

## 1. 供应商议价能力

高分含义：公司对上游有更强控制力，成本冲击更可控。

### 重点观察项

- 上游供应商是否集中在少数企业
- 核心原材料、设备、零部件是否可替代
- 公司是否具备规模采购、自研、自制或国产替代能力
- 上游涨价时，公司能否通过提价或产品升级消化成本

### 分数区间

| 得分 | 判断标准 | 常见信号 |
|------|----------|----------|
| 18-20 | 上游分散或公司具备强控制力 | 关键材料多来源、自供率高、成本波动对毛利率影响很小 |
| 14-17 | 上游可控，少量环节依赖头部供应商 | 采购规模大、可谈判、替代方案较成熟 |
| 10-13 | 有一定依赖，但尚未被上游卡脖子 | 关键材料部分依赖进口或寡头，成本波动会影响利润 |
| 6-9 | 上游高度集中，公司缺少替代能力 | 关键设备或材料依赖单一供应链，成本传导困难 |
| 1-5 | 上游垄断且公司明显弱势 | 成本与供给基本由供应商决定，利润弹性很差 |

## 2. 购买者议价能力

高分含义：公司对客户定价权更强，客户不容易压价或切换。

### 重点观察项

- 客户集中度是否过高
- 产品是否高度差异化，是否具备品牌、认证、技术或渠道壁垒
- 客户切换供应商的成本高不高
- 公司能否稳定提价并维持毛利率

### 分数区间

| 得分 | 判断标准 | 常见信号 |
|------|----------|----------|
| 18-20 | 公司强势主导交易条件 | 客户几乎无替代选择，品牌或技术壁垒极强，提价能力突出 |
| 14-17 | 客户有选择但切换成本高 | 产品差异化明显，复购稳定，毛利率具备韧性 |
| 10-13 | 双方议价相对均衡 | 客户可比价，但公司仍能靠产品和服务维持利润 |
| 6-9 | 客户强势，公司被动接单 | 大客户集中、同质化严重、价格压力大 |
| 1-5 | 公司几乎没有定价权 | 标准化产品、低门槛供给、价格战频繁 |

## 3. 新进入者威胁

高分含义：行业进入门槛高，新玩家难以撼动现有格局。

### 重点观察项

- 技术、资本、认证、渠道、品牌、产能、生态壁垒
- 新玩家从进入到达产、拿单、盈利所需时间
- 现有龙头是否具备规模效应、客户绑定、生态锁定
- 行业政策是否限制新增供给

### 分数区间

| 得分 | 判断标准 | 常见信号 |
|------|----------|----------|
| 18-20 | 进入壁垒极高，短中期难有实质新玩家 | 高研发、高资本、长认证周期、强生态锁定 |
| 14-17 | 壁垒较高，新玩家能进但难做大 | 需要多年积累，前期投入大，头部优势明显 |
| 10-13 | 存在壁垒，但可被时间和资本逐步突破 | 新玩家 3 到 5 年有机会形成竞争 |
| 6-9 | 壁垒偏低，进入速度较快 | 资本和技术要求一般，跟随者容易复制 |
| 1-5 | 几乎无明显进入门槛 | 新公司可快速进入并争夺份额 |

## 4. 替代品威胁

高分含义：公司产品或服务短中期不容易被替代。

### 重点观察项

- 是否存在成熟替代技术、替代材料、替代方案
- 替代路线是概念阶段、导入阶段还是产业化阶段
- 替代后下游客户的转换成本高不高
- 替代一旦发生，对公司收入和利润冲击是否显著

### 分数区间

| 得分 | 判断标准 | 常见信号 |
|------|----------|----------|
| 18-20 | 几乎不可替代，属核心必需环节 | 无成熟替代技术，需求刚性强 |
| 14-17 | 短中期替代风险低，仅远期有路线变化 | 有潜在新技术，但商业化较远 |
| 10-13 | 有一定替代可能，但冲击尚不直接 | 替代方案存在，但成本或性能暂不占优 |
| 6-9 | 替代风险已具现实性 | 3 到 5 年内可能被新技术或新材料侵蚀 |
| 1-5 | 替代已相当成熟 | 现有产品面临明显替代或需求萎缩 |

## 5. 同业竞争程度

高分含义：行业格局稳定，竞争理性，利润率不容易被内卷侵蚀。

### 重点观察项

- 行业集中度是否持续提升
- 是否存在价格战、补贴战、低价抢单
- 龙头企业是否拥有明显份额和盈利优势
- 行业是否已出清，尾部玩家是否持续退出

### 分数区间

| 得分 | 判断标准 | 常见信号 |
|------|----------|----------|
| 18-20 | 高度集中且竞争理性 | 近似垄断或强寡头格局，利润率稳定 |
| 14-17 | 格局较好，头部主导 | CR3 较高，价格战少，行业稳定扩张 |
| 10-13 | 格局中性，竞争可控 | 龙头有优势，但仍存在阶段性博弈 |
| 6-9 | 竞争偏激烈，盈利承压 | 玩家众多、低价竞争、行业利润率偏低 |
| 1-5 | 充分竞争甚至恶性竞争 | 无明显龙头，长期价格战，普遍低盈利 |

## 快速校准规则

### 哪些情况可以打高分

- 公司拥有稀缺技术、品牌、认证、渠道或生态位
- 即使行业周期波动，公司仍能保持较好毛利率和份额
- 与同行相比，关键维度存在明显结构性优势

### 哪些情况不要轻易打高分

- 竞争优势主要依赖短期景气而非长期壁垒
- 结论主要来自管理层表述，缺少行业或经营数据印证
- 细分行业尚未跑出稳定格局

## 输出建议

分析时可按以下格式浓缩每一力的依据：

```markdown
### 供应商议价能力：15/20
- 上游核心材料并非完全垄断，公司具备一定采购规模优势
- 但部分高端原料仍依赖少数供应商，成本波动会传导到毛利率
- 结论：议价能力中上，但未形成绝对主导
```
