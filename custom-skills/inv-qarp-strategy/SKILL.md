# 价值成长（QARP）选股与操作技能

## 核心定位

本技能是用户主打法"价值成长（QARP）"的执行层，解决的核心问题：

> 好公司不等于好股票，好价格才是买入理由。

**架构**：本技能依赖 `inv-valuation-engine` 提供估值引擎（脚本 + 定量评分框架），自身聚焦 QARP 特有的操作决策层：选股闸门 → 估值纪律 → 买入/持有/卖出 → 组合约束。

### 三个命令的使用场景

| 命令 | 场景 | 执行范围 |
|------|------|----------|
| `/qarp` | 新标的完整分析 | 估值快照 → 五档结论 → 三道闸门 → 估值纪律 → 买入必答 → 组合检查 → 结论 |
| `/qarp_screen` | 快速筛选是否值得深入研究 | 只跑选股闸门（三道），不跑完整估值。通过则输出"值得深入研究，建议 /qarp"，不通过则输出原因 |
| `/qarp_check` | 对已有持仓做持有/加仓/减仓检查 | 跳过闸门，直走估值快照 → 逻辑检查 → 估值检查 → 组合检查 → 持有/加仓/减仓/卖出结论 |

## 快速命令

估值脚本统一走 `inv-valuation-engine`。详见 `references/commands-quickref.md`。

## 一、估值框架（五档结论）

估值定量框架（公司类型识别、定量阈值、结论生成规则）以 `inv-valuation-engine` 的 `references/scoring-rules.md` 为权威标准，本技能只补充 QARP 特有的约束。

### 1.1 QARP 安全边际要求

| 标的类型 | 最低安全边际 | 买入最大估值上限 | 说明 |
|----------|-------------|-----------------|------|
| 龙头白马/宽护城河 | ≥20% | 内在价值的80% | 质量溢价可接受较小安全边际 |
| 成长股/中型公司 | ≥30% | 内在价值的70% | 增长不确定性需要更大保护 |
| 高波动科技股 | ≥40% | 内在价值的60% | 波动本身是风险来源 |
| 周期股/困境反转 | ≥50% | 内在价值的50% | 高不确定性需要极端安全边际 |

### 1.2 PEG 使用规则

- 仅用于盈利稳定、增速可估的标的（增速 10-30% 最适用）
- 增速取一致预期下限或自建保守假设，不用 Yahoo `earningsGrowth`
- 周期股、低增速成熟公司（<10%）、持续亏损公司不使用 PEG
- QARP 合理 PEG 区间：0.8-1.2

## 二、选股三道闸门

### 2.1 第一道：行业与商业模式

不通过则直接跳过，不看财务数据。

| 维度 | 要求 | 判断方法 |
|------|------|----------|
| 行业空间 | TAM 足够大，或渗透率仍在提升 | 查行业报告/研报，看行业增速 CAGR |
| 竞争结构 | 集中度提升中，或龙头护城河清晰 | CR3/CR5 趋势 + Porter 五力速判 |
| 商业模式 | 能说清"谁付钱、为什么付、凭什么持续付" | 用三句话测试，说不清则不通过 |
| 周期属性 | 明确标的属于成长/消费/周期/金融哪类 | 决定后续估值口径和持有逻辑 |

**商业模式速判清单**：
- 赚钱不辛苦：毛利率≥30%，净利率≥15%，低资本开支 → 优先
- 赚钱辛苦但能赚：毛利率 15-30%，需持续投入 → 要求更大安全边际
- 辛苦且不一定赚：低毛利、高波动、重资产 → 不符合 QARP，跳过

### 2.2 第二道：财务质量

| 指标 | 门槛 | 权重 |
|------|------|------|
| ROE | >15%（近3年均值） | 高 |
| 自由现金流 | 正值，FCF/净利润 >60% | 高 |
| 毛利率 | 行业前 1/3 或稳定提升 | 中 |
| 资本配置 | 分红+回购合理 | 中 |
| 资产负债表 | 净负债率合理 | 中 |

**允许 1-2 项不达标，3 项以上不达标则不通过。**

### 2.3 第三道：管理层评估（加分项）

- 资本配置纪律、激励一致性、对股东回报的态度（实际行动 > 口号）
- **管理层不达标不直接否决，但影响仓位上限（最多卫星仓位 2-5%）**

> 三道闸门中的研报输入细则（行业/TAM/竞争/财务趋势/管理层评价的提取方法）详见 `references/gate-research-input.md`。

## 三、估值纪律（QARP 核心）

### 3.1 估值-质量矩阵

| 场景 | 估值要求 | 仓位 | 操作 |
|------|---------|------|------|
| 好公司 + 估值合理 | PE 低于行业中位数或自身5年中位数 | 核心仓位 5-15% | 可以买入 |
| 好公司 + 估值贵 | PE 高于5年 75% 分位 | 不买 | 加入观察，等回调 |
| 一般公司 + 估值便宜 | PE/PB 处于历史低位 | 卫星仓位 2-5% | 小仓位博价值回归 |
| 一般公司 + 估值贵 | — | 不碰 | — |

### 3.2 QARP 估值合理区间判断

| 五档结论 | QARP 操作含义 |
|----------|--------------|
| 低估 | 积极买入，可给核心仓位 |
| 合理偏低 | 可以买入，正常仓位 |
| 合理 | 持有为主，新买入需谨慎、小仓位 |
| 合理偏高 | 不买入，持有者可考虑减仓 |
| 高估 | 不碰，持有者分批减仓 |

**关键规则**：好公司但估值贵时，建议加入观察等回调，而非追高建仓。

### 3.3 卖方共识交叉校验

卖方研报的盈利预测和评级需纳入估值判断，但**不能直接替代独立估值**：

| 用法 | 说明 |
|------|------|
| **增速假设参照** | 取多家研报的营收/EPS 增速预测区间，与自建假设对比。若自建假设远高于卖方共识（>5pp），需重新审视假设合理性 |
| **一致预期偏差警示** | 若当前 PE 远低于卖方一致预期隐含的合理 PE（即卖方普遍看多但市场不买账），说明市场在定价卖方未覆盖的风险，需深入调查 |
| **卖方乐观偏差修正** | 卖方目标价平均存在 10-15% 乐观偏差（尤其是承销关系券商）。使用卖方目标价时，按 0.85-0.9 系数打折后作为参考上限 |
| **分歧度信号** | 若各家目标价/盈利预测分歧极大（最高/最低 > 1.5x），说明标的未来高度不确定，应要求更大的安全边际（+10pp） |

**使用原则**：
- 卖方目标价**不**作为独立估值依据
- 卖方一致预期可作为增速假设参考，但必须人工校验合理性
- 卖方暗含风险应纳入本技能的风险框架
- 冲突时以财报事实为准

## 四、买入执行与组合管理

买入前必答清单、分批建仓规则、持有跟踪、卖出条件、组合约束 — 详见 `references/trade-execution-rules.md`。

核心纪律：
- 6 问全部有明确答案才可买入
- 单只股票仓位 ≤25%，首次建仓 ≤50% 目标仓位
- 逻辑破坏 → 果断卖出；估值透支 → 分批减仓
- 现金 <5% 停止新建仓

## 八、市场环境适配

详见 `references/trade-execution-rules.md`。核心：牛市不追高、震荡正常持、熊市加仓核心、利率上行偏价值。

## 九、执行流程

### 9.1 对新标的：三阶段

**阶段一（并行）**：A. `valuation_snapshot.py <代码> --output json` + B. 按 `inv-knowledge-curator` [深度挖掘协议](#) L2 标准深度搜索知识库——多角度搜索（标的/估值/风险/行业 ≥3 个角度）→ 跟随条目 `## 关联` 链 ≥1 层 → 标签导航收尾。搜索结果须按 `references/research-cross-validation.md` 的映射表结构化输出：共识观点（行业/TAM/竞争）→ 第一道闸门；财务趋势→ 第二道闸门；盈利预测区间→ 估值纪律 3.3；核心风险/隐含假设→ 买入必答。若知识库无记录，按 4.5 格式输出知识缺口。
**阶段二**：检查数据/知识覆盖缺口。若知识库有缺口，先输出结构化"知识缺口表"（按维度列出缺什么），再决定是否 WebFetch 降级补充。知识缺口表须标注每项缺口对后续分析环节的影响。
**阶段三（顺序）**：五档结论 → 选股闸门 → 估值纪律 → 买入必答 6 问 → 组合检查 → 结论 + 机会成本对比

### 9.2 对已有持仓：五步检查

估值快照 → 逻辑检查（买入理由/打脸条件）→ 估值检查（透支?）→ 组合检查（仓位/集中度）→ 结论（持有/加仓/减仓/卖出）

### 9.3 完整分析流程

```
阶段一(并行): A.估值快照 + B.知识库L2深度搜索(cross_refs ≥1层+结构化输出) → 阶段二: 知识缺口检查(缺口表→按需WebFetch补缺)
→ 阶段三(顺序): 五档结论 → 选股闸门 → 估值纪律 → 买入必答 → 组合检查 → 结论+机会成本对比
```

研报结构化输出流入各环节：卖方盈利预测→五档、行业/TAM→闸门、增速假设→估值纪律、核心风险→买入必答。

## 与其他技能配合

- **`inv-stock-data`**：数据层，所有行情与财务数据统一入口
- **`inv-valuation-engine`**：估值引擎，提供脚本 + 定量评分框架 + 大师框架
- **`inv-knowledge-curator`**：本地券商研报 PDF，提供卖方叙事、一致预期、盈利预测区间、风险与隐含假设。其结构化输出流入三道闸门、估值纪律、买入必答和机会成本比较。详见 `references/research-cross-validation.md`
- **`inv-porter-five-forces`**：五力竞争格局，用于第一道闸门的竞争结构判断
