# QARP 知识库研究与证据协议

目标不是“找到几篇研报”，而是识别会改变赚钱持续性、现金资本需求、保守回报或资本配置的重要未知，并用相应证据检验。知识库及图谱维护遵照 curator 原协议，不改、不减少；投资判断不依赖检索篮子、标签数、关联链深度、原文份数或双来源配额。

## 一、按重要未知确定研究范围

先读当前台账简洁卡、audit 与研究文件，识别本次需要解决的问题：命题是什么、哪项未知影响结论、何种证据能改变判断。首次研究完整覆盖四问；`/qarp_screen` 可初筛，未完整估值只标待测算、不授权交易。已有持仓按事件→受影响假设→所需证据增量复核，无有效基准或广泛变化再做完整研究。

L1/L2/L3 可描述实际研究范围，不按固定数量认证投资就绪。单一来源本身不触发升级；重要未知、来源冲突或重大风险未厘清才增加研究深度。不得用 index 或几篇摘要冒充深入研究。

## 二、问题驱动检索与图谱使用

先读 `entries/index.md`，针对关键问题搜索条目；按召回需要使用中文名、英文名、代码、关键变量与风险词。行业空间、竞争、现金、预测、治理、风险、时间变化是可选方向，不是必须凑满的篮子。

记录采用的来源路径、原始 resource、机构、真实日期及其回答的命题；同一原文的转载、重复摘要或共享终端共识不能当独立验证。按未知需要利用关联、标签、反向回链和时间线找补充、冲突及过时信息，不设条目数、标签数、链层数或命中数量要求。知识库建链、标签与反链维护仍按原协议执行，不能借此省略或删除维护。

## 三、按命题类型核验

| 命题类型 | 所需检验 | 不能替代的工作 |
|---|---|---|
| 官方原始事实 | 可单源：回溯财报、公告、监管披露，内部校验日期、币种、单位、期间、会计口径及勾稽关系 | 二手摘要、来源数量不能替代原始定位；公司指引不是已实现事实 |
| 预测 | 检查驱动、兑现条件、保守/基准/乐观假设、敏感性和主动反证 | 多家一致不证明预测正确；不能把指引当事实 |
| 因果解释 | 检验机制、相反证据、其他解释及可观察区分条件 | 多篇重复观点不证明因果 |
| 重大存疑事实 | 按风险与决策影响取得真正独立的验证，未澄清列重要未知 | 同源转载或复述不能消除疑点 |

主动提出并检验最强反对理由，检查永久损失与卖方盲点。反方可来自模型敏感性、不同经济解释或外部证据，不强求外部看空研报；找不到看空不等于没有风险。冲突定位分歧变量，不平均。

## 四、真实原文回溯

关键数字和决定性表述进入模型或结论前，回溯原始财报、公告或研报，不按资源份数过关。`entries/` 是二手加工，摘要遗漏口径、条件或风险须回原文补齐；无法定位标“摘要级/待核”，不得伪 verified。

现有本地原文读取方式：

```bash
python3 /Users/chengshun/.hermes/skills/inv-skills/inv-knowledge-curator/scripts/km_import.py read \
  --file /Users/chengshun/.inv-knowledge/{resource} --pages edges
```

`--file` 使用绝对路径或 `res/` 路径；resource 列表按相关问题逐项选择，不拼成一个参数。官方网页原文可记录 URL 与定位，不要求为原文配额另找 PDF。

每项关键证据记录数值/原话、真实日期、币种、单位、会计口径、已实现期间/预测期、原文路径/URL、可得页码或表格位置。对照摘要差异，检查相关风险及敏感性；不能仅读封面评级。具体数字影响估值、口径冲突、摘要省略条件或引用管理层原话时必须真实定位。

## 五、时间与事件有效性

按关键事实和假设变化组织时间线，比较基准与最新披露；不存在中间变化不补造日期或条目。禁止拼接不同日期预测为当前共识；历史事实保留回溯，不当未经复核的当前预测。

financial_report 及 financial 证据失效照现 schema 与 audit：invalidated 证据须真实复核并按协议追加版本，不能凭“经济上未受影响”自行设 verified。未受影响且台账仍有效的已核验证据才可复用，注明原核验与理由；`reviewed_through` 只填真实覆盖事件。

## 六、证据矩阵与完成标准

| 命题与类型 | 重要未知 | 原始来源与定位 | 日期/币种/单位/期间 | 口径校验或独立验证 | 反证/不同解释/敏感性 | 有效状态与结论影响 |
|---|---|---|---|---|---|---|

证据质量看原始真实性、适用性、口径、时效、机制及反证检验，不按份数分强弱。官方已披露事实优于对同项事实的卖方预测，原文优于摘要；独立验证用于实际疑点，不是通用双来源门槛。原文核验也不等于预测必然兑现。

输出研究范围、重要未知及核验结果、实际采用原文与复用记录、变化时间线（相关时）、反证和分歧、证据矩阵及剩余缺口；每条证据映射四问、情景、证伪或资本配置，不强制输出命中计数或固定维度表。

`knowledge_status=insufficient`：核心未知未核验、重大疑点未澄清或未认真检验反证，只能继续研究/观察，不买入加仓。`partial`：非核心缺口，说明对置信度与配置的影响。`ok`：当前重要未知已按命题类型充分处理，仍明示预测不确定性。重要未知仍待核，不能因取消配额伪就绪；QARP 不再以 v2 五类 evidence 认证为硬要求，新 v3 协议及旧记录兼容以 tracker 实际协议为准。
