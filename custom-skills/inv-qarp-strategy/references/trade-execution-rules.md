# QARP 资本配置与执行

## 四问先于动作

按 `../SKILL.md` 回答赚钱持续性、现金与资本需求、保守回报、证伪四问。每问须有证据和未知；不能回答则继续研究。行业机制解释财务质量，不用统一 ROE/毛利率/FCF 比例或不达标项数。欺诈、治理侵害与不可持续融资是红线，不能以小仓位绕过。

证伪条件来自原始披露、经济机制和主动反证，并补卖方盲点；反方可为模型敏感性或最强反对理由，不强求外部看空。写明标的特有变量、经济机制、可观测数据、时间维度及核验来源；数值条件需有该公司依据，不套通用阈值。触发后先查证影响，不机械买卖。

## 新增、加、减、换：同一资本配置问题

比较下一单位资本放在哪里，而不是分别凑不同操作清单：

| 选择 | 必答依据 |
|---|---|
| 新增/加仓 | 相对继续持有其他资产、替代机会及暂缓，在同口径保守情景下为何更优；下行风险与共同风险是否可承受 |
| 继续持有 | 剩余回报、可分配现金和风险仍可接受；交易并未提供经证据支持的优势 |
| 减仓/退出 | 逻辑或融资/治理红线变化、剩余回报不足或组合风险约束，说明事实和替代用途 |
| 换仓 | 继续持有 A / 换入 B / 暂缓三栏，同一数据时点、期限、币种与假设保守度，扣除税费、流动性及资金转换影响 |
| 暂缓 | 证据不足、无明确优势或执行条件未满足，不为输出动作而交易 |

价值结论与组合适配分开：组合限制不终止个股价值判断，但约束实际执行。缺可比数据不得只计算一边就宣称换仓优势；未有用户回报要求不得编目标收益率。

历史分位、价格位置、五档和卖方评级均非交易指令。卖方目标价仅核验其假设，不打固定折扣、不替代独立估值；分歧用具体变量与情景下行解释。

## 分批与资金执行

每次执行前读最新 `~/.hermes/memories/USER.md`，其仓位、行业集中度、首次建仓与分批规则为唯一用户约束，不在本文件复制数字以免漂移。分批节奏由用户规则及实际流动性决定；后续每批重新确认资本配置优势与证据有效性，不因首次买入后跌幅自动加仓，也不因牛熊标签交易。

核对各币种实际可用资金、结算、税费及换汇。现金仅记账不设历史最低/目标比例，不据此授权透支；不能用未到账工资或估算成交倒填余额，透支如实披露并核实清算与资金安排。

## 持仓只跟少数关键变量

每个标的选择能改变四问结论的少数变量（通常 2–4 个；不是 schema 字段或硬性计数），如客户留存、单位经济、维持资本、债务到期。写来源、基准、变化机制和下一可观测事件，不每季重做所有财务指标检查。

事件/财报/反证/重大价格变化只触发复核范围判断：
1. 先读当前台账简洁卡、audit 与研究文件；JUDGMENTS 仅历史参考，不是现行权威；报价只更新报价，不冒充研究。
2. 列事件影响哪个假设与哪些证据；新信息改变机制或现金/估值输入才重算相关情景。
3. 复用实际核验、未受影响且台账仍有效的证据，保留路径和核验定位；被 financial_report 事件失效的证据按现 schema 重新核验并追加版本，不虚设有效。历史事实仍可回溯，不能充作当前预测。
4. 按重要未知与命题类型增量核验并主动检验反证。官方原始事实可单源加内部口径校验，预测/因果看敏感性和不同解释，重大存疑事实按需独立验证；受影响证据须重核，不要求资源数量。无有效基准或广泛变化升级完整研究。
5. 输出变化/未变化/未知和是否改变配置结论；没有新增依据就沿用，不强造动作。

短期波动不等于逻辑破坏，逻辑未变也不等于应加仓。发现欺诈、流动性或不可持续融资须及时评估保护资本/退出，不等待既定阈值。

## 记录与完成

按 `judgment-journal.md` 仅在实质判断形成或变化时记录唯一源台账简洁卡，同一问题一次，不手工追加 JUDGMENTS 或双写；无实质变化沿用现卡，非判断不写。卡引用研究文件、情景、当时价格/日期/币种/单位/口径、四问依据及复核变量，真实持仓不在研究台账复制。PE/PB 分位可作历史背景，不是必填决策依据。

新台账协议为 v3 并兼容旧记录；简洁卡一次写入使用 `decision_ledger.py --db <台账绝对路径> apply --file <批次JSON绝对路径>`，字段见 `inv-portfolio-tracker/references/decision-ledger.md`；QARP 不再以 v2 五类 evidence 认证为硬要求，重要未知仍待核，financial 失效照现 audit，建议版本绑定及问题关闭按实际协议；建议/确认/执行分离，成交以真实来源记账。未经用户确认不得执行；不直接编辑数据库、CURRENT 或持仓来替代协议。

必要写入后收尾读回台账简洁卡、audit 与生成视图一致性，说明阻塞步骤。结论末尾保留：
- 关键假设：有来源的少数驱动因素。
- 失效条件：可观测且可验证的复核事件。
