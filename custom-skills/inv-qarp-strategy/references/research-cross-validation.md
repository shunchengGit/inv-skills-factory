# 研报与决策框架的交叉验证

研报不是一次性的"提取→贴入模板"，而是贯穿 QARP 全流程的交叉验证工具。

**原文优先**：本文件中的"研报"指原始研报 PDF 或可定位的原始发布页面，而非 `entries/` 摘要条目。进入交叉验证表的结论，凡是关键数字或定性判断，默认要求原文级核验；只有摘要依据的，按弱信号处理（见信号强度表）。

## 研报输出到决策环节的映射

| 研报结构化产出 | 流入 QARP 环节 | 用法 |
|---------------|---------------|------|
| 共识观点（行业/TAM/竞争） | 赚钱持续性 | 行业空间判断的事实依据 |
| 共识观点（财务趋势） | 现金与资本需求 | ROE/FCF/毛利率趋势的卖方判断 |
| 管理层评价 | 赚钱持续性/资本配置 | 资本配置纪律、股东回报态度 |
| 盈利预测区间 | 保守回报/情景估值 | 增速假设校验、一致预期对照 |
| 分歧观点 | 保守回报/情景估值 | 定位分歧变量及其对保守情景、永久损失的影响，不加固定折扣 |
| 核心风险 | 证伪 | 打脸条件制定的输入 |
| 隐含假设与失效条件 | 证伪 | 逻辑破坏型卖出条件 |
| 卖方盲点 | 资本配置 | 仓位上限调整（高不确定性 → 降低仓位） |
| 交叉验证点 | 五力/估值 | 供下游技能引用的具体验证点 |

## 按命题类型评估证据

- 官方原始事实允许单源加内部口径校验：真实回溯财报、公告、监管披露，核对日期、币种、单位、期间、会计口径和勾稽。单源本身不降级；存在重大疑点则按需独立验证。
- 预测检验驱动、兑现条件、情景敏感性与反证；因果检验机制、相反证据和不同解释。公司指引和卖方预测都不是已实现事实，多家一致也不能认证正确。
- 重大存疑事实需适当独立验证；同一原文转载、共享终端共识或重复摘要不算独立。未厘清的重要未知保留待核，不伪就绪。
- 主动检验最强反对理由及卖方盲点；反方可为模型敏感性或不同解释，不强求外部看空研报。没有看空不等于没有风险。
- 原文优于摘要；财报实际值与预测分开。冲突定位期间、口径或分歧变量，调查经济原因，不平均或机械加折扣。

不以来源数、原文份数或 v2 五类 evidence 认证分强弱；记录实际核验、未知与结论影响。具体命题类型和证据矩阵见 `knowledge-deep-search.md`。

## 无本地研报时的降级路径

当 `~/.inv-knowledge/res/index.md` 无匹配时，按以下优先级降级：
1. **Web 降级**：用 数据层 取分析师一致预期/目标价、Firecrawl 抓公开研报摘要、搜索引擎补非 A 股标的研报数据（详见本技能 `references/web-search-supplement.md`）
2. **标注信息缺口**：在输出模板的证据与缺口部分明确标注"无本地研报，已走 Web 降级 / 无可用研报"，并说明对分析完整性的影响
