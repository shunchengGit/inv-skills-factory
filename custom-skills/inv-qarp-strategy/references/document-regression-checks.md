# 决策与检索文档回归检查

仅检查 Markdown；不取行情、不写知识库、不认证旧研究、不触发 cron。仓库根运行 `python3 .claude/skills/skill-linter/scripts/lint_skills.py` 与 `git diff --check`，再核对以下场景：

| 场景 | 应保留 | 不应出现 |
|---|---|---|
| 行情刷新 | 报价时点、有效基准、回报变化、复核触发 | 重研究、就绪认证、新判断卡 |
| 财报或其他事件 | 受影响命题/期间/证据、差分、未知、audit 实际状态 | 全组合重估、自行改绿、猜 tracker 字段 |
| 新增资本/换仓 | 实际四问、主估值与独立辅助校验、三情景、代表性替代/暂缓同口径回报 | 全组合大矩阵、档位映射动作 |
| 加减仓入口 | QARP 路由、工具执行测算、用户约束、建议/确认/成交分离 | 独立策略、现金底线、重复评审 |
| 正式研报入库 | 摘要≥3句、关键要点≥3条、来源与口径/风险正文、真实关联 | 为数量造链、摘要冒充核验 |
| Note 短笔记 | 真实内容与必要字段/来源 | 强凑三句/三点、数字、关联 |
| 历史原文 | 按命题/期间/修订/事件判断时效、可回溯事实 | 183天统一拒绝引用、自动删除 |
| 知识库维护 | index、标签、关联/反链、图谱、现有 CLI、curator 单写入者 | 默认最低 L2、角度/关联数量认证投资就绪 |

审阅修改清单应仅含四个授权技能的 Markdown，专题 references 保留；其他并行任务的文件不属于本检查。数量与结构通过不证明投资判断正确，重要未知和真实反证仍须处理。
