# 常见陷阱与防范

| 陷阱 | 防范 |
|------|------|
| 好公司买贵了，等估值消化 2-3 年 | 用来源明确的保守情景、永久损失风险和机会成本判断，历史中位数不判买卖 |
| 逻辑变了不肯认错 | 写清可观测证伪条件，触发后查证经济影响并复核配置，不机械执行 |
| 追热点买自己不懂的行业 | 四问说不清赚钱持续性与资本需求就继续研究，不用统一行业/毛利门槛 |
| 仓位太集中 / 现金太少 | 读取最新 USER.md 的仓位和集中度约束；现金只核对币种可用余额，不设旧目标比例 |
| 频繁交易 | 少数变量、事件增量复核；期限按情景明确，不强制造交易 |
| PEG 陷阱：短期高增速不可持续 | 增速取一致预期下限，不用单季 GAAP `earningsGrowth` |
| Forward PE 口径失真 | 互联网/科技公司（腾讯/阿里/美团等）的 Yahoo Forward PE 常基于 Non-GAAP 调整后 EPS，隐含增速虚高（>30%）。对齐价格时点、会计口径与预测期；仅同口径时可作隐含增速校验，异常则核验原文并重算，不因固定增速阈值替换主锚点。A+H 双上市额外注意 GAAP vs Non-GAAP 差异 |
| 互联网公司 GAAP 净利润失真 | 参见 `inv-valuation-engine` 的 `inv-valuation-engine/references/internet-platform-valuation.md`，用 Normalized 净利润。**注意**：Normalized Income 同比增速也可能失真——当对比基期含一次性投资收益/减值时，应优先用**经营利润（Operating Income）增速**作为核心增长指标 |
| AI CapEx 暴增期 FCF 失真 | 互联网平台在 AI 基础设施投资周期中，CapEx 可从营收 20%+ 跳升至 35%+，导致 FCF/NI 从 >80% 降至 <80%。此时 FCF 下降可能来自投资支出，也可能反映利润质量恶化，须核验，不能预设解释。判断方法：依据公司披露和行业机制核验维持/增长投入及回报，不能按固定营收比例加回或默认新增支出都有价值；无法拆分时以范围情景和缺口表达 |
| 5年价格分位受极端值扭曲 | 5年区间若包含极端暴跌（如 2022 年 META 从 $384→$89、中概股集体暴跌），分位会被严重拉低。价格位置与估值分位均只作背景，不能相互替代或判买卖；回到现金、情景回报与永久损失 |
| 脚本增速假设需校验 | 运行 valuation_report.py 后检查增速是否来自 `earningsGrowth`，若是则人工替换 |
| valuation_report.py 数据不足时输出极简 | 当底层脚本因数据源失败返回极少字段时，valuation_report.py 可能仅输出极简结论。应视为脚本失败，降级为手动按估值框架计算，不得将极简报告结论作为 QARP 五档判断依据。标注"脚本数据不足，已手动计算" |
| 搜索功能用于金融查询效率低 | 搜索引擎对金融查询低效+CAPTCHA。增量信息优先走 数据层 + 本地研报，最后才考虑网页抓取 |
| 卖方目标价当独立估值依据 | 卖方存在结构性乐观偏差（承销关系、佣金依赖）。卖方目标价只追溯假设与分歧，不设固定折价参考上限，不替代独立估值。一致性高不等于正确——2008 年 crisis 前卖方对金融股评级也高度一致 |
| 卖方共识 = 市场共识 | 卖方共识 ≠ 市场定价。若当前 PE 远低于卖方一致预期隐含 PE，说明市场在定价卖方未覆盖的风险——这正是需要深入调查的盲点 |
| 研报同质化误判 | 多数卖方研报共享 Bloomberg 一致预期数据源，看似"多家一致"实则同源。真正的独立判断来自不同研究框架（如买方视角 vs 卖方视角、定量模型 vs 定性调研）的交叉验证 |
| 忽视研报"暗含风险" | 研报末尾的风险提示（下行风险、敏感性假设）通常比封面的"买入"评级更有价值。卖方不在封面写的风险（地缘政治、技术颠覆、管理层变动）往往是真正的关键风险 |
| 忽视卖方盲点 | 卖方系统性忽视某些风险类型（如台海地缘对台积电、AI 投入从被奖励到被惩罚的转折）。需在分析中主动补充卖方未覆盖的尾部风险 |
| H2 兑现门槛用错基数 | 计算"全年预测减 H1 后 H2 需增长多少"时，分母必须是**上年同期 H2 实际值**（上年全年 − 上年 H1），不能拿上年全年或本年 H1 当基数。基数错会把 +12% 的温和门槛夸大成 +40% 的高压门槛，进而误判为"不宜加仓"。上年 H1 可由本期 H1 与同比增速倒推：H1_prev = H1_now / (1 + yoy) |
| A 股加仓忘记检查币种 | 组合现金栏是折算后的 CNY 合计，可能全部是美元/港币。A 股标的加仓前必须确认**人民币现金余额**本身足够，否则估值再便宜也无法执行；结论应写"等弹药到账后分批"，而非笼统的"可加仓" |
| 摘要当原文 | curator 条目是二手加工，会省略假设条件和口径注释。关键数字（TAM、EPS 预测、目标价）未回溯原文就写进估值模型，等于把转述误差直接计入安全边际——先定位原始财报、公告或研报（本地资源可用 `km_import.py read`）并核对日期、币种、单位与口径后再采用 |
| 假交叉验证 | 重复摘要或多家券商共享同一终端的“一致”不算独立验证。官方原始事实可单源加内部口径校验；预测/因果主动检验反证及不同解释，重大存疑事实按需独立验证；重要未知仍待核 |
