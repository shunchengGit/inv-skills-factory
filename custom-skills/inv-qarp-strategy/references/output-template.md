# QARP 输出模板

## 新标的 QARP 分析

```
## QARP 分析：[标的名称]（[代码]）

### 估值快照
- 数据时点：[日期]
- PE：[xx]（[xx]年分位 [xx]%）
- PB：[xx]（[xx]年分位 [xx]%）
- 增速假设：[xx]%（来源：[一致预期/自建假设]）
- PEG：[xx]
- 安全边际：[xx]%
- 五档结论：低估 / 合理偏低 / 合理 / 合理偏高 / 高估

### 知识库深挖与卖方证据链
（严格执行 `knowledge-deep-search.md`；只罗列研报标题不算完成）

- knowledge_status：{ok / partial / insufficient}
- 搜索深度：{L2+ / L3}
- 检索审计：{覆盖的证据篮子；直接命中 N / 关联扩展 N / 反向回链 N / 最终采用 N}
- 来源独立性：{N 家独立机构；同机构重复已去重}
- 日期窗口：{最早 ~ 最晚；fresh/aging/stale 分布}
- 原文回溯：{至少2份资源路径；关键反方/分歧是否覆盖}

| 维度 | 状态 | 条目数 | 最新时点 | 核心证据/缺口 | 流入决策 |
|------|:--:|:--:|---------|---------------|----------|
| 行业空间 | {✅/⚠/❌} | {N} | {日期} | {TAM/CAGR} | 第一道闸门 |
| 竞争格局 | {✅/⚠/❌} | {N} | {日期} | {市占率/护城河} | 第一道闸门 |
| 财务质量 | {✅/⚠/❌} | {N} | {日期} | {ROE/FCF/毛利率} | 第二道闸门 |
| 盈利与估值 | {✅/⚠/❌} | {N} | {日期} | {EPS/目标价/假设} | 估值纪律 |
| 风险与反方 | {✅/⚠/❌} | {N} | {日期} | {关键反方} | 打脸条件 |
| 管理层/资本配置 | {✅/⚠/❌} | {N} | {日期} | {回购/分红/激励} | 第三道闸门 |

#### 时间线与观点漂移
| 时点 | 来源 | 指标/观点 | 相比前次 | 对 QARP 的影响 |
|------|------|-----------|----------|----------------|
| {日期} | {来源} | {事实/预测} | {上修/下修/不变} | {闸门/估值/风险} |

#### 共识、分歧与反方
- 一致预期：{营收/EPS增速区间，口径与预测期}
- 主要共识：{至少2家独立来源支持的结论}
- 关键分歧：{分歧变量及其根源，不做简单平均}
- 主动寻找的反方证据：{下调/低于预期/尾部风险；找不到则标注缺口}
- 目标价区间：{最低~最高；0.85-0.9折价后仅作参考上限}
- 卖方盲点：{研报未覆盖但必须独立考虑的风险}

#### 核心证据矩阵
| 命题 | 财报/行情事实 | 来源A | 来源B/反方 | 时效 | 强度 | 冲突处理 | 流入决策 |
|------|---------------|-------|-------------|------|------|----------|----------|
| {命题} | {事实} | {机构/资源} | {机构/资源} | {fresh等} | {强/中/弱/冲突} | {裁决} | {环节} |

### 增量信息缺口检查
（逐级确认，缺哪级补哪级，全部覆盖才能出结论）

- [ ] yfinance 已覆盖：{列出已获取的关键字段}
- [ ] 研报已覆盖：{已覆盖的观点/数据，或"无本地研报"}
- [ ] 关键缺口：{列出 yfinance+研报均未覆盖的信息}
- [ ] Agent WebFetch 补充结果：{已补充的内容，或"无需补充"}

### 选股闸门
- 第一道（行业与商业模式）：通过 / 不通过 — [理由]
- 第二道（财务质量）：通过 / 不通过 — [达标项/不达标项]
- 第三道（管理层）：通过 / 不通过 — [理由]

### 估值纪律
- 估值-质量矩阵定位：[好公司+估值合理 / 好公司+估值贵 / ...]
- 五档结论：[低估~高估]
- QARP 操作含义：[积极买入 / 可以买入 / 持有观望 / 不买 / 不碰]
- 卖方共识校验：{增速假设 vs 卖方一致预期区间；目标价分歧度；乐观偏差修正后参考上限}

### 买入前必答
1. 行业商业模式看得懂吗？[是/否，一句话]
2. 核心竞争优势？[一句话]
3. 估值位置与安全边际？[PE xx，x年分位xx%，安全边际xx%]
4. 买入理由？[一句话]
5. 打脸条件？[一句话]
6. 目标仓位？[xx%，分x次建仓]

### 机会成本对比
| 标的 | 估值 | 质量 | 风险 | 仓位建议 |
|------|------|------|------|----------|
| {当前标的} | {五档} | {高/中/低} | {高/中/低} | {xx%} |
| {对比标的1} | {五档} | {高/中/低} | {高/中/低} | {xx%} |

### 组合检查
- 当前仓位：[xx%]
- 行业集中度：[xx%]
- 现金比例：[xx%]
- 是否允许新建仓：[是/否]

### 结论
- 操作建议：[买入 / 观察 / 不碰]
- 价格区间：[理想买入价 xx - xx]
- 分批计划：[第1批 xx%，第2批 xx%]
- 打脸条件：[一句话]
```

## 持仓 QARP 检查

```
## QARP 持仓检查：[标的名称]（[代码]）

### 估值快照
- 数据时点：[日期]
- 当前 PE/PB：[xx / xx]
- 历史分位：[xx]%

### 知识库 L2 核验
- knowledge_status：{ok / partial / insufficient}
- 检索审计：{5个必需证据篮子；直接/关联/反链/采用数量；独立机构数}
- 最新证据时点：{日期；相比上次检查的观点漂移}
- 原文回溯：{至少1份；涉及调仓至少2份}
- 反方证据：{已找到并核验 / 覆盖缺口}
- 核心证据与冲突：{事实、来源、强度、裁决}
- 知识缺口对操作影响：{无 / 降低置信度 / 禁止调仓动作}

### 逻辑检查
- 买入理由：[原买入理由]
- 是否还成立：[是/否，变化说明及证据]
- 打脸条件：[原打脸条件]
- 是否触发：[是/否，事实与来源]

### 估值检查
- 是否透支未来增长：[是/否]
- QARP 操作含义：[持有 / 加仓 / 减仓]

### 组合检查
- 当前仓位：[xx%]
- 行业集中度：[xx%]

### 结论
- 操作建议：[持有 / 加仓 / 减仓 / 卖出]
- 执行计划：[具体操作步骤]
```
