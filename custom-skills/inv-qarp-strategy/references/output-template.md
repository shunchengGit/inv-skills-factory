# QARP 输出模板

## 新标的 QARP 分析

```
## QARP 分析：[标的名称]（[代码]）

### 估值快照
- 数据时点：[日期]
- PE：[xx]（[xx]年分位 [xx]%）
- PB：[xx]（[xx]年分位 [xx]%）
- 增速假设：[xx]%（来源：[一致预期/自建假设]）
- PEG：[xx]
- 安全边际：[xx]%
- 五档结论：低估 / 合理偏低 / 合理 / 合理偏高 / 高估

### 卖方研报摘要
（读 `entries/` 条目摘要 + 覆盖情况；关键数据点不足时用 `km_import.py read --file {resource} --pages edges` 回溯 `res/` 原始研报首尾页。无本地研报则标注并说明降级方案）

- 覆盖情况：{N 篇，{最早} ~ {最晚}，时效性 fresh/aging/stale}
- 一致预期：{营收增速 xx%、EPS xx}
- 主要共识：{1-2 条}
- 关键分歧：{1-2 条}
- 目标价区间：{最低 ~ 最高}（打折后参考上限：{xx}）
- 核心风险（研报列出）：{1-3 条}
- 卖方未覆盖的尾部风险：{补充卖方盲点}
- 财务预测对照：{卖方 ROE/FCF/毛利率预测 vs yfinance 历史数据}
- 与管理层相关的定性信息：{有/无，简述}
- 数据时点：{研报日期窗口}

### 增量信息缺口检查
（逐级确认，缺哪级补哪级，全部覆盖才能出结论）

- [ ] yfinance 已覆盖：{列出已获取的关键字段}
- [ ] 研报已覆盖：{已覆盖的观点/数据，或"无本地研报"}
- [ ] 关键缺口：{列出 yfinance+研报均未覆盖的信息}
- [ ] Agent WebFetch 补充结果：{已补充的内容，或"无需补充"}

### 选股闸门
- 第一道（行业与商业模式）：通过 / 不通过 — [理由]
- 第二道（财务质量）：通过 / 不通过 — [达标项/不达标项]
- 第三道（管理层）：通过 / 不通过 — [理由]

### 估值纪律
- 估值-质量矩阵定位：[好公司+估值合理 / 好公司+估值贵 / ...]
- 五档结论：[低估~高估]
- QARP 操作含义：[积极买入 / 可以买入 / 持有观望 / 不买 / 不碰]
- 卖方共识校验：{增速假设 vs 卖方一致预期区间；目标价分歧度；乐观偏差修正后参考上限}

### 买入前必答
1. 行业商业模式看得懂吗？[是/否，一句话]
2. 核心竞争优势？[一句话]
3. 估值位置与安全边际？[PE xx，x年分位xx%，安全边际xx%]
4. 买入理由？[一句话]
5. 打脸条件？[一句话]
6. 目标仓位？[xx%，分x次建仓]

### 机会成本对比
| 标的 | 估值 | 质量 | 风险 | 仓位建议 |
|------|------|------|------|----------|
| {当前标的} | {五档} | {高/中/低} | {高/中/低} | {xx%} |
| {对比标的1} | {五档} | {高/中/低} | {高/中/低} | {xx%} |

### 组合检查
- 当前仓位：[xx%]
- 行业集中度：[xx%]
- 现金比例：[xx%]
- 是否允许新建仓：[是/否]

### 结论
- 操作建议：[买入 / 观察 / 不碰]
- 价格区间：[理想买入价 xx - xx]
- 分批计划：[第1批 xx%，第2批 xx%]
- 打脸条件：[一句话]
```

## 持仓 QARP 检查

```
## QARP 持仓检查：[标的名称]（[代码]）

### 估值快照
- 数据时点：[日期]
- 当前 PE/PB：[xx / xx]
- 历史分位：[xx]%

### 逻辑检查
- 买入理由：[原买入理由]
- 是否还成立：[是/否，变化说明]
- 打脸条件：[原打脸条件]
- 是否触发：[是/否]

### 估值检查
- 是否透支未来增长：[是/否]
- QARP 操作含义：[持有 / 加仓 / 减仓]

### 组合检查
- 当前仓位：[xx%]
- 行业集中度：[xx%]

### 结论
- 操作建议：[持有 / 加仓 / 减仓 / 卖出]
- 执行计划：[具体操作步骤]
```
