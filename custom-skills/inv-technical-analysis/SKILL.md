# 短线量价与盘中执行

## 定位

用于A股、ETF和港股的短线量价判断。只回答价格结构、成交量、确认条件和执行纪律；不得用短线信号替代基本面判断。用户明确要求纯价值/价值成长时切换到QARP，不把技术位置混入绝对价值结论。

## 标准流程

1. **先读组合上下文**：涉及已有持仓或具体买卖数量时，读取绝对路径 `~/.hermes/memories/PORTFOLIO.md`，取得股数、仓位、同币种现金和组合上限。
2. **每次追问都刷新行情**：盘中数据数分钟即可失效。用户说“突然回落”“现在呢”“今天能买吗”时必须重新抓取，不复用上一条回复的价格、VWAP或成交额。
3. **抓三层数据**：实时快照、当日分钟线、至少60—120根日线。优先走已部署的 `inv-stock-data`；A股/ETF的QQ Finance确定性降级见下方命令。
4. **先判断结构，再谈买点**：依次检查现价相对VWAP、从日内高点回撤、回撤期间增量成交量/额、关键位是否失守、5/10/20日均线与近期放量日。
5. **区分“可以买一点”与“确认反转”**：放量反弹、站上均线只支持右侧试仓；突破压力位并经收盘或回踩确认，才支持提高仓位。禁止把“胜率改善”写成“趋势已反转”。
6. **输出机械条件**：给出限价区间、最大股数/金额、撤单条件、停止买入条件、第二笔间隔和新增仓失效位。已有底仓与新增趋势仓分开管理。
7. **重新计算组合影响**：用实时价测算买后股数、仓位、剩余同币种现金；不得把美元/港币现金默认视为可立即购买人民币资产。

## A股/ETF盘中确定性抓取

```text
# 快照
https://qt.gtimg.cn/q=sh588000

# 分钟线：HHMM price cumulative_volume cumulative_amount
https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh588000

# 前复权日线，末尾数字为根数
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh588000,day,,,120,qfq
```

请求带 `User-Agent: Mozilla/5.0` 与 `Referer: https://finance.qq.com/`。港股快照代码使用 `hk02020`；深市使用 `sz` 前缀。

分钟线成交量、成交额是累计值：

```python
vwap = cumulative_amount / cumulative_volume / 100
interval_volume = end_cumulative_volume - start_cumulative_volume
interval_amount = end_cumulative_amount - start_cumulative_amount
```

日线与分钟线成交量口径可能相差100倍；计算成交额前用实时快照核对单位。绝不能把累计量当单分钟量，否则会误判突然放量。

## 盘中判断框架

### 强势延续

- 现价持续高于VWAP；
- 回踩缩量，重新站回前一短周期平台；
- 上涨日成交量显著高于20日均量；
- 压力位突破后没有快速跌回。

只满足前三项但未突破压力位：定义为“强反弹/试仓条件”，不是反转确认。

### 冲高回落

- 从日内高点连续下行；
- 回撤段增量成交额明显放大；
- 价格跌破VWAP且无法快速收回；
- 原计划限价区间失去承接。

此时立刻撤掉高于当前结构的未成交单，等待重新站回VWAP或下一支撑止跌；不要因为几分钟前给过“可以买”而维护旧结论。

## 用户坚持当天买入时

不与用户争论等待次日确认，但必须降低不可逆风险：

- 首笔通常控制在计划加仓量的25%—50%；
- 用限价单，不用市价追涨；
- 写明高于何价不追、低于何价撤单；
- 当天只执行一笔，第二笔至少间隔一周，除非用户明确改变其长期交易纪律；
- 新增趋势仓设置独立失效位，原有中期底仓不因一两日波动机械卖出。

## 输出格式

第一行直接给“现在买/暂停/等待确认”及具体数量。随后只保留：

1. 数据时点与4—6个关键量价指标；
2. 当前结构为什么支持或否定买入；
3. 限价、数量、撤单条件；
4. 成交后的失效条件和下一笔规则。

盘中回复要短，避免重复公司长期逻辑。方向改变时明确说“条件已变化”，并指出是哪一个实时指标失效。

## 常见陷阱

- 每次盘中追问都刷新数据，因为价格、VWAP和成交额会在几分钟内改变结论。
- 用时段累计值做差后判断抛压，因为直接读取分钟线累计量会夸大单分钟成交。
- 先写压力和失效位再给买单，因为只给买入理由会诱发追涨和补仓。
- 将底仓与新增仓分开，因为短线信号失效不等于中期投资逻辑破坏。
- 不以“仓位低”证明价格值得买，因为购买能力和估值/量价优势是两个问题。
