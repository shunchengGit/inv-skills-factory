# 同口径资本配置比较

本参考不维护独立质量评分或优先级，唯一判断协议为 `inv-qarp-strategy`。

## 比较内容

- 同一价格日期、期限、币种与盈利口径下，比较保守回报及不利情景损失。
- 企业质量表现为现金流可预测性、资本需求、竞争机制和治理证据，不按护城河名称固定排序。
- ROE、FCF转化率按行业及资本周期解释，不使用跨行业统一门槛。
- 好公司不必然优于便宜的另一家公司；价格、风险和证据共同决定吸引力。
- PE/PB相近不表示同估值，同样增长不表示同现金回报。
- 关键证据缺失时标待核，不用历史案例或模糊质量等级代替当前估值。

## 输出

继续持有、替换、暂缓并列；说明最影响排序的变量及反转条件。真实数字用工具计算，事实、机构预测和自建假设分开。
