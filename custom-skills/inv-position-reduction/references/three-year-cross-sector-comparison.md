# 三年跨行业持仓比较检查表

## 建模与证据

1. 先定共同起止日期。若退出日在9月而锚为当年全年EPS，标明前瞻全年预测，不能称已实现盈利；不额外增加持有月数。
2. 净资产模型列出起点财报日与估值日之间的桥接。冻结半年报BVPS作为9月起点只能是显式代理，随后三年滚动值不能未经桥接称12月末实际BVPS。ROE为平均权益口径时，不把直接乘期初权益的简化计算伪装成精确会计预测。
3. 将股息按预计支付日纳入持有期，排除起点之前已付和退出后才付的股息。银行连续期留存模型与实际年度分红存在时差时，披露代理假设，避免两股收现口径不对称。
4. 银行核验普通股净资产、资本监管要求与RWA增长；分红与增长受资本约束，不能同时假设高扩表、高派息且零稀释。重装核验受限现金、债务、金融子公司存款及履约需求；可分配净现金未知时不估值加回。
5. 每股两家独立机构分别记录原文日期、页码、预测期和是否为财报后更新模型。记录官方事实及反方，不把多篇同机构报告计为独立共识。
6. PDF首尾抽取只是导航：检查实际页码及截断说明；本次验证 `km_import.py read --pages all --max-pages 220 --max-chars 600000` 可读长报告。页数和字符预算按具体文件调整，不把默认edges输出当完整模型核验。曾从77页报告第63页找到公司EPS/DPS，第一页行业摘要不足以支持估值。
7. 冲突不要平均化：HoH/QoQ是不同期间，维持评级不等于此次下调；原文有中英文单位或表述差异时定位财务表，不继承摘要错误。

## 回报与交付

- 本币总回报=(期末价格+期间实收股息)/当前可卖价格-1；三年年化=(1+总回报)^(1/3)-1。现金不再投资时这是终值年化，不称逐期股息IRR。
- 跨币种按明确FX路径换算；恒定汇率是情景假设，不冒充实时已验证汇率。成本不影响换仓机会成本。
- 价格快照时间不等于交易日；休市日标成“当日收盘”的持仓记录应重新核验。未验证行情只能生成条件回报。
- 保留自动引擎原始状态、错误与人工情景状态。自动公司类型未识别或价格分位冒充估值分位时，不采纳自动五档结论。
- 截止前预留检查窗口：后台启动不是完成；读取退出码与错误后再落最终MD/JSON；校验两文件存在、非空、JSON可解析、情景数量及状态一致。
- 缺证据允许交付完整条件敏感性分析，但knowledge_status/action必须如实降级；不以牛情景弹性替代风险调整后的换仓理由。熊情景也不是尾部损失下限。
